# Cover Pop / 社交封面

> 把一个选题变成「会被点开」的社交封面：小红书首图、公众号封面、视频封面、朋友圈头图。

Cover Pop 面向所有需要发内容的普通人——写小红书、发公众号、做视频、发朋友圈的人。它不是一个滤镜或模板包，而是一套封面工作流：先想清楚「谁在刷、为什么停下、点进来能得到什么」，再把这件事做成一张标题清楚、钩子明确、不土不微商的封面。

封面只有一个任务：让对的人停下来，点进去。如果封面赢不了这一下点击，后面写得再好也没人看。

## 它解决什么问题

普通人做封面常掉进几个坑：标题党空心（点进来啥也没有）、信息过载（什么都想塞）、微商风（金红渐变 + 贴纸堆）、AI 塑料感（文字糊成一团、手指六根）。

Cover Pop 想要另一种状态：

- 标题在缩略图大小下一秒能读懂
- 一张封面只讲一个承诺、一个主体
- 配色克制：一个底色、一个强调色、一个墨色
- 看起来像一个真实的、值得关注的账号，而不是广告
- 同一个账号的多张封面风格统一，但每张贴合自己的选题

一句话判断：如果一个目标读者刷到这张图不会停下，这张封面就还没做完。

## 适合谁

适合：小红书 / 公众号 / 视频号 / 抖音 / 朋友圈的内容作者，产品、生活、知识、美食、穿搭、教程类选题。

不适合：正文长图配图（用插画类 skill）、logo、表情包、信息密集的数据图。

## 工作流

1. 读选题、标题想法或笔记草稿。
2. 找出目标读者，和他正在刷的那个瞬间。
3. 写核心承诺：点进来能得到什么。
4. 从 `references/cover-archetypes.md` 选一个封面原型（大字 / 反差 / 清单 / 教程 / 情绪 / 实拍 / 盘点）。
5. 跑「停下测试」：这个读者会停吗？承诺是真的吗？
6. 用 `references/title-formulas.md` 写标题——短、具体、缩略图能读。
7. 用 `references/style-dna.md` 定外观、配色、版式。
8. 用 `references/prompt-template.md` 生成最终图像提示词。
9. 一次生成一张。
10. 用 `references/qa-checklist.md` 验收，不过就重做。

## 安装

### Codex

```bash
mkdir -p ~/.codex/skills
cp -R cover-pop ~/.codex/skills/cover-pop
```

重启后：

```text
用 $cover-pop 给这个选题做一张小红书封面：「3 步写出不尬的朋友圈文案」。先规划，先别生成。
```

### 其他 Agent（Claude Code / Cursor / Hermes / OpenClaw）

不需要 Codex Skill 格式，把 `SKILL.md` 和 `references/` 当作项目指令 / 规则 / workflow prompt 贴入即可。核心链路是：
`目标读者 -> 核心承诺 -> 停下测试 -> 选原型 -> 写标题 -> 最终提示词 -> QA`。

注意：跨 Agent 复用的是规划和提示词工作流；最终成图质量取决于图像模型，尤其是中文标题的渲染。文字渲染不干净时，按 `prompt-template.md` 的 text-fix 流程修，或先留空标题框、再在编辑器里叠字。

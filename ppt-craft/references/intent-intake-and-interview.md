# Intent Intake And Interview

## Principle

Do not start with blank-page design. First digest the user's material, infer a Deck Brief v0, then ask only the questions that change the outcome.

Asking is useful for decks because the same source can become a live keynote, investor teaser, board memo, sales proposal, classroom lesson, or social carousel. These need different density, proof, and style. But too many questions destroy flow, so ask 0-3 questions with recommended defaults.

## Digest First

For a source document, PPTX, PDF, notes, or URL, extract:

- Core thesis: the one sentence the audience must remember.
- Audience and stakes: investor, client, manager, team, student, public reader.
- Conversion goal: fund, approve, buy, align, learn, remember, share.
- Narrative raw material: problem, enemy/current state, solution, proof, mechanism, traction, economics, roadmap, team, ask.
- Emotional register: urgent, premium, trustworthy, technical, warm, playful, cinematic, institutional.
- Evidence types: charts, screenshots, testimonials, case studies, citations, demos, financials.
- Constraints: language, confidentiality, editability, page count, brand assets, deadline.

For a short prompt, infer the same fields and mark missing items.

## Deck Brief v0

Write this before asking:

```text
- recommended route:
- recommended density:
- likely style family:
- missing decisions:

```

## Ask 0-3 Questions

Ask only when the answer would change route, story, or style.

Priority order:

1. **Audience/setting**: "Who is this mainly for: investors, clients, internal leadership, or public sharing? Default: I will infer from the source."
2. **Output/editability**: "Should the final be maximum-beauty HTML/PDF, or native editable PPTX? Default: HTML-first unless PowerPoint editing matters."
3. **Narrative freedom**: "Should I preserve the source order/wording, or restructure into the strongest story? Default: restructure if this is a new deck; preserve if this is an existing deck polish."
4. **Style direction**: "Do you want conservative/premium/cinematic/technical/playful, or should I show 3 directions? Default: show 3 directions for non-trivial decks."
5. **Length/density**: "Is this for a live talk or async reading? Default: investor/client decks become self-contained but not bloated."

If the user is absent or asked to proceed, continue with the defaults in the brief and state assumptions in the route note.

## Good Intake Behavior

- Show the user that their material was understood before asking.
- Prefer "I infer X; please correct me if wrong" over a blank questionnaire.
- Ask fewer questions when the source is strong.
- Ask more only when the user has given no source and the deck has high stakes.
- Never ask for facts that can be extracted from supplied files or researched.

## Bad Intake Behavior

- Asking for style before understanding the message.
- Asking the user to choose from vague labels without showing visual evidence.
- Generating slides directly from a long document without a thesis and arc.
- Treating "make it beautiful" as sufficient direction.
- Letting user questions postpone obvious extraction, research, or reference analysis.

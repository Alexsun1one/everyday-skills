# Rank Cards / 排名·段位卡

> 把「谁更强」变成一张专业排名卡：球星历史地位、GOAT 金字塔、顶级 vs 普通、Top 10 段位卡——发视频号、抖音、小红书。

Rank Cards 面向所有做排名/盘点内容的人。最近视频号上很火的球星段位卡（顶级后卫 vs 普通后卫、历史地位排名、GOAT 金字塔）就是这类。它不是普通生图——是一套**整体排版 + 选图 harness**：每个人的头像怎么统一处理、tier 怎么分、排名依据是什么、文字名次徽章放哪，全部约束死。

同一套 harness 通用：足球、篮球，也能排作家、音乐家、导演、科学家、动漫角色、产品——**只换三个适配项**（头像、道具、依据），骨架不动。

## 它解决什么问题

排名卡做砸通常是两件事：**像拼贴**（各扒一张照片，裁切、底色、画风全不一样），和**没依据**（凭感觉排，评论区「你算老几」）。

Rank Cards 用两道闸门顶住：

- **统一头像 pipeline**：所有人同一种裁切、同一个底、同一种处理（默认双色调）、同一种描边、同一种画风——像同一个摄影师同一天拍的。这是「专业 vs 拼贴」的分水岭。
- **排名依据上卡**：强制写明依据（历史地位 / 巅峰统治力 / 荣誉 / 数据 / 影响力）和范围（现役/历史·位置·俱乐部/国家队），印在卡上。把「个人暴论」变成「有标准的判断」。

再加上：3–6 档、平行命名、暖→冷配色（红 S/神 → 蓝 D）、顶档稀缺、清楚的文字层级。

## 适合谁

适合：做球星/明星排名、历史地位盘点、Top N 榜单、谁更强对比、段位卡的视频号/抖音/小红书作者。

不适合：单纯一张封面（用 `cover-pop`）、纯文字金句卡（用 `quote-cards`）、没有排名/对比的内容。

## 工作流

1. 定要排谁、什么角度。
2. 定范围：现役/历史、只排某位置、俱乐部还是国家队、巅峰还是生涯。
3. 选排名依据（`references/tier-and-criteria.md`），印到卡上。
4. 选 tier 系统：一套词表、3–6 档、顶档稀缺。
5. 列人 + 分档 + 定每个人的年代/球衣/照片。
6. 跑「排名成立测试」：依据写了吗？所有头像走同一条 pipeline 吗？
7. 选版式（`references/layout-archetypes.md`）：封面用领奖台/对决/金字塔/单人卡；轮播用分档行/网格。
8. 锁头像 pipeline（`references/portrait-pipeline.md`）——这是核心。
9. 按领域换三个适配项（`references/domain-adaptation.md`）。
10. 出最终提示词（`references/prompt-template.md`），一次一张。
11. 用 `references/qa-checklist.md` 验收，拼贴/无依据/档太多/名字看不清就重做。

## 安装

### Codex

```bash
mkdir -p ~/.codex/skills
cp -R rank-cards ~/.codex/skills/rank-cards
```

```text
用 $rank-cards 做一张「历史最强后卫段位卡」：按巅峰统治力，仅限现役。先规划，先别生成。
```

### 其他 Agent

把 `SKILL.md` 和 `references/` 当项目指令 / 规则 / workflow prompt 贴入即可。核心链路：
`定范围 -> 选依据 -> 分档 -> 锁头像 pipeline -> 选版式 -> 最终提示词 -> QA`。

想要更高级的视觉，可以叠加同仓库的 `master-styles`（大师视觉语言）当审美引擎，比如「Platon 式紧贴高反差肖像 + 瑞士网格」。

注意：跨 Agent 复用的是规划和提示词工作流；最终成图（尤其中文文字、真实球星相似度）取决于图像模型。文字渲染不干净时，按 `prompt-template.md` 的 text-fix 流程修，或先留空文字/名牌、再在编辑器里叠字。

# Expression Library

This is the main reference. A sticker pack is only useful if its stickers cover the chat
moments people actually send. Pick chat moments from this taxonomy, give each a caption,
and keep the whole set on one character.

Each entry gives the chat moment (when the user sends it) and a caption example (≤ 6 字,
网络口吻). Rename or reword captions in the user's own voice — keep them short and real.

## Chat-Moment Taxonomy

### 打招呼 / Hello

Chat moment: 开聊、戳一下、进群报到。
Caption examples: "在吗" · "嗨呀" · "冒个泡"

### 赞同 / 点赞 / Agree

Chat moment: 对方说得对，表示「+1」。
Caption examples: "对对对" · "说得好" · "+1"

### 拒绝 / 不要 / No

Chat moment: 被安排活、被拉去聚会，礼貌或不礼貌地拒。
Caption examples: "不去" · "拒绝" · "我不要"

### 摆烂 / 躺平 / Lie flat

Chat moment: 不想努力了，破罐破摔。
Caption examples: "摆烂" · "躺平了" · "爱咋咋地"

### 打工人累了 / Worker exhausted

Chat moment: 加班、被甩活、周一早上。
Caption examples: "好累" · "打工魂" · "下班了吗"

### 委屈 / Aggrieved

Chat moment: 被误会、被凶、求安慰。
Caption examples: "委屈" · "我错了吗" · "呜呜"

### 生气 / Angry

Chat moment: 被气到、要发飙、表示不满。
Caption examples: "生气" · "气死了" · "哼"

### 求饶 / 认错 / Begging / Sorry

Chat moment: 闯祸了、被抓包、赶紧认错。
Caption examples: "我错了" · "饶命" · "对不起"

### 笑死 / 绷不住 / Dying laughing

Chat moment: 看到好笑的、绷不住了。
Caption examples: "笑死" · "绷不住" · "哈哈哈"

### 已读不回 / 在吗 / Ghosted

Chat moment: 对方已读不回、催回复、确认还活着。
Caption examples: "在吗" · "人呢" · "已读不回?"

### 催 / 快点 / Hurry up

Chat moment: 等人、催进度、催回消息。
Caption examples: "快点" · "催了" · "等到花谢"

### 彩虹屁 / 夸人 / Praise

Chat moment: 夸对方、拍彩虹屁、商业互吹。
Caption examples: "你最棒" · "爱你" · "yyds"

### emo / 难过 / Down

Chat moment: 心情低落、想被关心。
Caption examples: "emo了" · "难过" · "丧"

### 吃瓜 / 围观 / Watching drama

Chat moment: 群里有瓜、坐等后续。
Caption examples: "吃瓜" · "围观" · "继续说"

### 晚安 / 早安 / Good night/morning

Chat moment: 睡前道晚安、早上问好。
Caption examples: "晚安" · "早安" · "睡了"

### 谢谢 / 比心 / Thanks

Chat moment: 收到帮助、表示感谢、比个心。
Caption examples: "谢谢" · "比心" · "蟹蟹"

Cover the moments the user's circle actually uses. A daily-use pack usually wants 打招呼,
赞同, 摆烂, 笑死, 已读不回, 催, 夸人, and 晚安 at minimum. Add or drop to fit the character.

## Character Consistency

The whole pack must look like one character. This is the first quality moat.

Fixed traits — keep identical across every sticker:

- silhouette / body shape
- palette (same colors in the same roles)
- head shape and face layout
- line weight and rendering style
- one signature accessory (hat, scarf, blush, tail shape)

Only change between stickers: pose, expression, prop, caption.

Recommended technique — model sheet first:

1. Generate a MODEL SHEET: the character in a neutral pose plus a few expressions on one
   sheet (角色三视图 or a 表情九宫格). This locks the identity.
2. Treat the model sheet as the source of truth.
3. Derive each sticker from it: "same character as the reference, new pose + expression +
   caption", changing nothing in the fixed traits.
4. If a sticker drifts off-model, pull it back to the model sheet and regenerate — do not
   keep a wrong character just because the pose is good.

## Caption

**Lock the character's verbal register BEFORE writing any caption** — one tic chosen up front
(always polite / always deadpan / always 凶巴巴 / always 文绉绉…), recorded in the character DNA.
**Failure mode:** captions that are interchangeable generic meme-speak (笑死 / yyds / 绝绝子
sprinkled uniformly) — every such caption is filler. **Rule:** at least 2/3 of captions in the
set must only make sense in THIS character's voice; rewrite any caption that would read
identically on a stranger's sticker. Avoid platform buzzwords that will date the pack within a
year unless the buzzword IS the character's bit.

The caption is half the sticker. Rules:

- ≤ 6 字, big and readable at small chat size
- placed top or bottom, off the character's face, with clean contrast
- 网络用语口吻 — type it the way people text (笑死 / 摆烂 / yyds), not 书面语
- correct Chinese characters — no melted, doubled, or gibberish glyphs
- caption and expression must say the same thing; mismatched text + face kills the joke

# Aesthetic Routing

The sticker set's visual register is chosen BY THE CHARACTER VIBE / theme — automatically. The
user does not name a style. A 国潮/古风 character routes to an ink/工笔 register; a cute mascot
routes to rounded pop; a minimal brand character routes to reductive flat. Route ONCE, then
lock that register across the whole set — the register is part of the consistency moat.

Routing and consistency are one decision here: pick the register, then it is frozen into the
character DNA so every sticker shares it.

## Route by character vibe → register

| Character vibe / theme | Register | Tokens to apply (locked across the set) |
| --- | --- | --- |
| 可爱 / 萌系 / 治愈 (pets, soft mascots) | 圆润流行 (Olimpia Zagnoli) | soft rounded organic silhouettes, a tested high-saturation palette, flat and buoyant, bold instant-read shape |
| 国潮 / 古风 / 国风角色 (古装, 武侠, 仙侠, 神兽) | 水墨 / 工笔 (Chinese ink) | ink-line or fine 工笔 outline, rice-paper or flat warm ground, mineral-pigment accents, a small 印章 mark; keep it sticker-clean, not a full painting |
| 极简 / 高级 / 品牌吉祥物 | 减法扁平 (Geoff McFetridge) | reductive faceless-leaning simplicity, muted matte palette, clean contour, one signature shape |
| 大胆 / 撞色 / 潮玩 | 剪纸纯色 (Matisse cut-outs) | pure flat color shapes, the cut edge as the line, bold contrasting blocks, rhythmic |
| 沙雕 / 搞怪 / 梗图 | 大头扁平卡通 (bold flat cartoon) | oversized expressive head, thick even outline, flat fills, exaggerated emotion, punchy 2-3 color palette |
| 复古 / 怀旧 | 印刷怀旧 (retro print) | limited retro palette, slight halftone/print texture, rounded vintage forms |
| 酷 / 潮 / 街头 | 街头波普 (bold pop / Scher energy, sticker-scaled) | punchy palette, confident bold shapes; keep it clean enough to read at chat size |

## How to route

1. Read the character idea + theme (a 柴犬? a 古装侠客? a 品牌 IP? a 沙雕梗角色?).
2. Pick the register from the table. Culture/theme wins: a 古风/国潮 character routes to the
   ink register regardless of cuteness.
3. **Lock the register into the character DNA** — it becomes one of the frozen traits, applied
   identically to the model sheet and every sticker. Changing register mid-set breaks the pack.
4. The expression/pose/caption still vary per sticker; the register never does.
5. The user may override; the default is the routed register, never a generic AI doodle.

**Tie-breaker (in order):** (1) explicit cultural/historical theme wins over cuteness —
古风/国潮/古装/武侠/仙侠/神兽 ALWAYS routes to 水墨·工笔 even when the character is cute; (2) an
established brand/IP look the user supplied wins next; (3) stated mood (沙雕/极简/撞色) wins last.

**Default register when nothing is stated** (a bare pet photo or generic vibe): route to 圆润流行
(Zagnoli rounded pop) — the safest send-ready everyday look — and say so in the plan. Never leave
the register unrouted or default to a generic AI doodle.

## Compatibility rule

A sticker must read at small chat size and cut out cleanly. Only route to registers that stay
bold and legible when tiny — no fine ornament that turns to mush, no busy collage. The ink
register here means a clean ink-line sticker, not a dense scroll painting.

## The ink register (国潮/古风 characters, often missed)

For 古风 / 国潮 / 古装 / 武侠 / 仙侠 / 神兽 characters, default to: a confident ink-brush or fine
工笔 contour, a flat warm or rice-paper ground (still keyable to transparent), one or two
mineral-pigment accents (朱砂红/石青), and optionally a tiny 印章 as the signature mark. Keep it
sticker-simple and bold — borrow the ink LINE and palette, not a full 山水 scene. See the
East-Asian section of the master library for the tokens.

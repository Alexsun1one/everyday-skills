# Prompt Records / 提示词留档

For public examples, README/showcase, article packages, or reusable builds.

## Minimal Record

```text
asset name:
source anchor:
asset role:
relationship type:
mode + because:
parts / ×N counts:
truth constraints:
native elements used:
final prompt:
output path:
rejected attempts:
QA result:
caption:
```

## Rejected Attempts Worth Keeping

- garbled Chinese / invented modules
- decorative bricks / arrow collapse
- LEGO logo or trademarked set
- voxel/Minecraft drift
- Swap Test fail / template lock
- wrong mode for the job
- text not on a brick carrier

# Layout Handoff / 版式交接

Use when a brick image will sit inside README, article, WeChat, social card, slide, doc, or knowledge base.

LEGO Town creates the **structure image**. The outer layout may own headline, body, CTA, ratio, and caption.

## Handoff Fields

```text
final container:
image role:
recommended ratio:
safe margin:
headline inside image: yes/no
caption outside image:
crop guidance:
background requirement:
handoff owner:
```

## Ratio Guidance

| Container | Ratio | Notes |
| --- | --- | --- |
| README / article | 16:9 | default |
| Social-card well | wide + strong safe margins | avoid edge tiles/flags |
| Slide center | 16:9 or 4:3 | leave text-safe zones |
| Box art / card | 1:1 or 4:5 | banner needs top margin |
| Instruction sheet | 16:9 or page-like | keep call-out box readable |

## Crop Rules

- Focal build module in the central ~70%.
- Instruction call-out boxes and box-art banners need top/side safe margin.
- Dense towns: simplify rather than ask layout to crop chaos.

## Delivery Notes

Include: full path, preview path if any, recommended caption outside, crop warnings, small-display safety.

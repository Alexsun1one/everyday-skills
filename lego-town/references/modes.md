# Modes / 四种成像模式

The mode is the most LEGO-native decision: it decides whether the reader sees the **finished thing**, the **way it's assembled**, the **parts it's made of**, or a **cover**. Choose one mode per image. The mode follows the job, not taste.

| If the job is… | Use mode |
| --- | --- |
| show a whole structure / system / relationship / town at once | **Finished Build** |
| explain a process / prompt / workflow / document outline / how-to (order matters) | **Instruction Sheet** |
| show anatomy / components / "what's inside" / parts-of-a-good-X | **Exploded View** |
| a title / cover / hero for a doc or deck | **Box Art** |

A series may pair modes: Box Art opener → Instruction Sheet middle → Finished Build resolution.

---

## 1. Finished Build / 成品模式

The assembled scene on a baseplate, shot like an official set photo.

**Use for:** a system shown whole, a town/map, a comparison (two finished builds), an org, an architecture, a "here is the thing."

**Compose:**
- a clean **baseplate** as the ground; one focal build module raised slightly; supporting modules around it; a simple skyline of low bricks in back for depth.
- **studio product light**: soft key, gentle fill, soft contact shadow, a seamless light-gray/white sweep or a subtle ground.
- the **connection is visible** (see `connection-grammar.md`): you can see what sits on what, what a road joins, what a wall contains.
- labels on **printed tiles, signboards, road signs, plinth plaques**.
- 0–3 minifigs only if one performs a live action (a builder mid-snap, an inspector at a gate).

**Reject:** a pretty cityscape that explains nothing; equal-weight blocks with no focal module; a glossy generic 3D render with no stud/clutch honesty.

---

## 2. Instruction Sheet / 说明书模式 — the signature mode

The iconic build-booklet look. This is the strongest mode for **documents, prompts, workflows, and how-tos**, because it shows *assembly order*, not just a result.

**Use for:** a prompt's parts (system → context → instruction → format as steps 1–4), a pipeline, a setup guide, a recipe, a document's section outline built up step by step.

**Compose:**
- **numbered step panels** (1, 2, 3, 4…) in a clean grid or vertical flow; each panel shows the build *as it looks after that step*, with the newly added parts highlighted.
- an **exploded "add these" arrow** in each step: the new bricks hover just above their slot with a thin drop-line.
- a **parts call-out box** per step or in a corner: small icons of the bricks needed with a count, e.g. `2×4 砖 ×3`, `1×2 印字砖 ×1`, `小人仔 ×1`. This is the unmistakable LEGO-manual signature.
- **flat, even, shadow-light vector/booklet render** (not dramatic studio light); off-white page, thin frame, a step-number badge in a circle.
- a small **finished preview** thumbnail in a corner ("what you're building").
- labels = the step numbers + short tile captions + the call-out counts.

**Reject:** a single step pretending to be a manual; dramatic photographic light (that's Finished-Build mode); call-out boxes with fake illegible part counts.

**Prompt-as-build example:** Step 1 places the **System** baseplate; Step 2 snaps on the **Context** bricks; Step 3 adds the **Instruction** beam; Step 4 caps it with the **Format/Output** tile. The reader sees a prompt is *assembled in order from optional and required parts* — far clearer than a bullet list.

---

## 3. Exploded View / 爆炸图模式

Components separated and hovering along thin vertical connection lines, in assembly order — the classic technical exploded diagram, in bricks.

**Use for:** anatomy ("the parts of a good README"), component architecture, "what's inside this system," a teardown, a layered stack pulled apart.

**Compose:**
- the build **pulled apart vertically (or along one axis)**; each module floats at its station, aligned to where it slots in; thin dashed **drop-lines** connect each part to its socket.
- order top-to-bottom or front-to-back = assembly order or layer order.
- each floating module gets a **label tile or a leader line to a caption** naming its job.
- a faint **ghost of the assembled whole** may sit to one side for reference.
- clean even light, light ground; depth via the float spacing.

**Reject:** parts scattered with no alignment or drop-lines (that's a mess, not an exploded view); so many parts the slots are unreadable — group into ≤7 modules.

---

## 4. Box Art / 盒面模式

The front of the build's box: a title/cover image.

**Use for:** a doc/deck hero, a section cover, a "set" that bundles a whole topic.

**Compose:**
- the hero build shot at a dynamic 3/4 angle, often on an action backdrop hinting at the theme.
- an **original product-name banner** (the topic's name) — bold, readable, top or corner.
- a small **spec strip**: an age-style badge, a "piece count" that maps to the topic's scope, a "minifig ×N included" corner.
- one accent color drawn from the build; premium box-photography light.
- **Original brand only**: never the LEGO logo/wordmark; use an original mark or the user's own brand. The product name is the topic, not a real set name.

**Reject:** the LEGO logo or a real set's box; a cluttered cover with no clear hero build; fake legal/marketing text.

## Mode × Relationship hints

- **Dependency / Hierarchy** read best as **Finished Build** (you see the load) or **Exploded View** (you see the layers).
- **Sequence / Transformation / Causality** read best as **Instruction Sheet** (order is the point).
- **Contrast** reads best as **Finished Build** with a split baseplate.
- **Anatomy / "parts of"** reads best as **Exploded View**.
- A **topic cover** is **Box Art**.

## Accept / Regenerate

Accept: the mode matches the job; the signature cues are present and legible (studio light for finished; numbered steps + part call-outs for instruction; aligned floats + drop-lines for exploded; original banner + spec strip for box art); one focal build; readable labels.

Regenerate: the mode fights the job (a process shown as a static finished build loses the order; an anatomy shown as box art hides the parts); the signature cues are missing or faked; a real set/logo/licensed character appears.

# Brick Library / 搭建原型与小人仔

Two things live here: **build archetypes** (the verbs — how a relationship is physically assembled) and **minifig roles** (the actors — who performs the live action). Pick one build archetype per image, and 0–3 minifig roles. Rename them in the user's language; keep the visual DNA consistent.

Read with `connection-grammar.md` (the relation each archetype serves) and `primitives.md` (the elements each is built from).

## Build Archetypes / 搭建原型

Each: what it shows — how it's built — the relation it serves.

### Structure & Dependency

- **Load-Bearing Stack / 承重塔** — what depends on what — modules stacked on a foundation slab/pillars; pull the base and it topples — *Dependency, Hierarchy.*
- **Walled District / 围合街区** — what contains what — fenced plots / nested baseplates, one cutaway wall exposing the inside — *Containment, Hierarchy.*
- **Cutaway Building / 剖面楼** — the inside of a whole — a building with one wall removed, rooms/floors labeled — *Hierarchy, Anatomy.*
- **Foundation Slab / 地基板** — the shared base everything needs — one large plate all modules clutch onto — *Dependency.*

### Flow & Process

- **Conveyor Line / 流水线** — ordered stages with handoff — a belt of plates with numbered stations and chutes — *Sequence, Handoff.*
- **Relay Road / 接力道** — ownership moving stage to stage — a baseplate road, a different minifig per station — *Sequence, Handoff.*
- **Road Fork / 岔路** — where work splits by a rule — a road switching into labeled lanes at a lever — *Divergence.*
- **Funnel Hopper / 漏斗** — many inputs to one output — lanes feeding a hopper that drops one module — *Convergence.*
- **Build Machine / 加工机** — raw turns into finished — a machine a part passes through; gray-rough in, bright-finished out — *Transformation.*

### Force & Decision

- **Brick Seesaw / 跷跷板** — a tradeoff weighed — a balance beam tilting toward the heavier side; a discard bin for cost — *Tradeoff.*
- **Gear Train / 齿轮组** — coupled feedback — meshed Technic gears; turning one turns the loop — *Feedback.*
- **Governor / 调速器** — a balancing loop that damps — a gear loop with a valve/counterweight holding it steady — *Feedback (balancing).*
- **Lever & Gate / 杠杆闸** — a trigger fires an effect — a lever/button that drops a barrier or lights a brick — *Causality.*
- **Tug Anchors / 张拉锚** — forces held in balance — a suspended module pulled by bands between two towers — *Tension.*

### Comparison & Connection

- **A/B Split Plate / 对照板** — two options differ by one part — twin builds on a split baseplate, one swapped module — *Contrast.*
- **Bridge Span / 桥接** — two modules joined across a gap — a bridge/road/hose coupling with a contact point — *Connection.*
- **Checkpoint Gate / 关卡** — what passes an edge — a gate with sorted pass/fail piles, an inspector — *Boundary, Filter.*

### Place & Map

- **Baseplate Town / 小镇地图** — a whole system as districts — modules as buildings, roads as relations, a skyline for depth — *System map, Hierarchy + Connection.*
- **Knowledge Town / 知识小镇** — a field as a town — concepts as districts, prerequisites as foundations, a learning road with numbered stops — *Education map.*
- **Roadmap Lanes / 路线图** — phases over time — parallel baseplate lanes with milestone builds and a timeline curb — *Sequence over time.*

## Build Verb Bank

Strong (the build *does* something): stack, snap, connect, bridge, route, sort, gate, gear, mesh, weigh, balance, split, merge, wall-off, contain, expose (cutaway), assemble, transform, anchor, suspend, support.

Weak (avoid as the core idea): display, decorate, pose, scatter, fill space, "just a city."

## Minifig Roles / 小人仔角色

Minifigs are **original** role-actors defined by accessories + a printed torso, never by a named/licensed identity. Use 0–3. Each must perform one live action (see the Minifig Test in `style-dna.md`).

- **Builder / 搭建师** — hard hat, a brick in hand, mid-snap — *the work is in progress; assembly is happening.* Tools: brick, baseplate, instruction sheet.
- **Inspector / 质检员** — clipboard, magnifier, stamp at a gate — *a check, approval, or QA.* Tools: clipboard, stamp tile, magnifier.
- **Courier / 接驳员** — satchel/parcel on a road — *a handoff or route.* Tools: parcel brick, cart, road.
- **Operator / 操作员** — at a lever, valve, or console — *control, triggering, regulating.* Tools: lever, valve, control panel.
- **Mayor / 镇长** — chain of office, on a plinth — *ownership of a module or district.* Tools: plinth, plaque, ribbon.
- **Surveyor / 制图员** — map, flag, theodolite — *mapping the town, planning the layout.* Tools: folded map, flags, transit.
- **Researcher / 研究员** — lab goggles, a test module — *experiment, analysis, discovery.* Tools: beaker brick, magnifier, sample tray.
- **Guide / 向导** — pointer at a signboard, leading along a road — *teaching, a learning path, a tour.* Tools: pointer, sign, numbered stops.
- **Maintainer / 维护员** — wrench, a cracked module being repaired — *fixing, recovery, upkeep.* Tools: wrench, patch brick, jack.

### Minifig expression (original, state only)

Calm dot-eyes + a small neutral line by default. Angle the brows for **effort/focus** at a hard task; a small downward line near a **risk-coral** part for **strain/warning**; a gentle up-line at a **mint-green** finished module for **satisfaction**. Keep it abstract and original — never copy a trademarked smiley print, never a licensed face, never realistic features. One expression per minifig; in a series, let it progress with the build state.

## Two-Minifig & Three-Minifig Scenes

Use more than one minifig only when the relation is between parties and one would hide the structure:

- **Handoff** (Courier → Builder at a station): ownership changes hands.
- **Comparison/Negotiation** (two Mayors across an A/B plate or a seesaw): two sides held visible.
- **Build-in-progress** (Builder + Inspector): work plus a check.

Rules: keep one focal action; both minifigs smaller than the build; each holds one side of the relation (a parcel, a stamp, a beam arm, a shared road). Never turn the image into a cast posing for the camera. Regenerate if the extra minifig only adds charm or symmetry.

## Accept / Regenerate

Accept: one build archetype that physically performs the named relation; 0–3 minifigs each doing a live action; the build is the hero; elements come from `primitives.md`.

Regenerate: the archetype doesn't match the relation; a minifig only stands and waves; a crowd of characters; a named/licensed minifig; the build is decorative and the meaning survives without it.

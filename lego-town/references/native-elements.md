# Native Elements / 乐高原生元素词汇

LEGO ships its own vocabulary of meaningful parts — arrow road-plates, stop signs, striped barriers, gears, traffic lights, trans-stud "lights", clipboards. Anyone who has held a brick reads them instantly: an arrow road-plate = "flow this way", a striped barrier = "stop/danger", a gear mesh = "this drives that", a trans-red stud = "alarm". **Prefer the element that already means what you need.** Using a real native element is both more legible and what makes the image feel like authentic LEGO instead of a generic blocky 3D render. This is a primary defense against genericness.

Read with `primitives.md` (the abstract kit), `connection-grammar.md` (the relation each serves), `state-coding.md` (color/state), and `lettering-and-text.md` (signage that also carries text). Stay original — these are generic produced part *types*, never a specific licensed set, never the LEGO logo.

## How to use this file

When you reach for a primitive, ask: **is there a native LEGO element that already signals this?** If yes, use it — it carries meaning for free and looks unmistakably like bricks. Each entry: element — what it natively signals — relation family it serves.

## Directional & Indicator / 方向与指示

These tell the eye where to go and what the rule is — without a drawn arrow.

- **Printed road baseplate (lane arrows) / 印箭头路板** — flow direction, a route — *Sequence, Connection.*
- **Arrow tile / arrow road-plate / 箭头砖** — "this way", step direction — *Sequence.*
- **Road signs (directional / stop octagon / yield / no-entry / speed) / 路牌·禁停·让行** — a rule at a point, a junction decision — *Boundary, Divergence.*
- **Traffic light brick / 红绿灯** — gate/state: red=block, amber=hold, green=go — *Causality, Boundary.*
- **Striped barrier / danger-stripe brick (red-white / yellow-black) / 警示条** — caution, do-not-cross, a hard boundary — *Boundary, Tension.*
- **Boom gate / barrier arm / 道闸** — pass/hold/block posture — *Boundary, Filter.*
- **Flag / banner on a pole / 旗** — a milestone, a claim, owned territory — *Sequence (milestone), Hierarchy.*
- **Signpost / pointing minifig / 指路牌** — "you are here", a guide's direction — *Connection, orientation.*
- **Number / letter studs on the road / 路面编号** — station order, lane id — *Sequence.*

## Mechanism / 传动机构

These natively mean "X drives, gates, or couples Y" — motion you can read.

- **Technic gears (meshed) / 齿轮咬合** — coupling, transmission, feedback — *Feedback Loop.*
- **Axle / 轴** — a shared drive, one source turning many — *Dependency, Connection.*
- **Pin & beam / 销与梁** — a rigid mechanical link or frame — *Dependency, structure.*
- **Hinge / click-hinge / 铰链** — an adjustable or conditional angle — *Transformation, conditional Connection.*
- **Ball-and-socket joint / 球窝关节** — flexible / loose coupling, an adjustable interface — *Connection (loose).*
- **Turntable / 转盘** — rotation, cycle, scheduling, round-robin — *Feedback Loop.*
- **Flexible hose / ribbed tube / 软管** — a soft feed or loose connection — *Connection (soft).*
- **Chain / tread links / 链条·履带** — a linked sequence, a conveyor — *Sequence.*
- **Rubber band / 皮筋** — tension, pull, suspension — *Tension.*
- **Lever / 2×2 switch / 拨杆** — a trigger or control input — *Causality.*
- **Pneumatic / valve piece / 气阀** — flow regulation, rate control — *Feedback (balancing), Boundary.*
- **Funnel / hopper / 漏斗** — many-into-one collection — *Convergence.*
- **Rail switch / points / 道岔** — a fork that routes by a rule — *Divergence.*

## State & Signal / 状态与信号

- **Trans-clear / trans-color round 1×1 "light" stud / 透明灯点** — a live signal/energy: trans-red=alarm, trans-green=go, trans-blue=active data — *state coding.*
- **Light brick (glows) / 发光砖** — active / on / triggered — *Causality, state.*
- **Printed gauge / dial tile / 仪表片** — a reading of intensity or health — *Feedback, measure.*
- **Printed computer-screen tile / 屏幕片** — data, output, an interface — *Transformation output.*
- **Control-panel printed slope / 控制台斜面** — an operator interface — *Causality.*
- **Stud-meter (row of 1×1 round plates) / 点阵计量** — quantity by count — *degree.*

## Structural Connectors With Meaning / 有含义的结构连接件

These encode *how* parts relate, beyond plain stacking.

- **Jumper plate (offset stud) / 偏置板** — a half-step, a fine offset, precise alignment — *fine Sequence, calibration.*
- **Bracket / SNOT piece (studs not on top) / 转向砖** — a subsystem turned 90°, a different facet/orientation — *Hierarchy (a face of the whole), Transformation.*
- **Clip-and-bar / 卡扣** — a detachable or optional attachment — *optionality, Divergence.*
- **Hinge plate / 翻折板** — a fold-out or expandable section — *Transformation, extensibility.*
- **Plate vs tile cap / 薄板与盖片** — sub-layer vs finished-sealed surface (studs exposed = to-build; tiled = done) — *state coding.*
- **Modular plug-in bay (spare studded slots) / 插槽舱** — extension points, future modules, optionality — *Divergence, Connection.*

## Iconic "Dot" Vocabulary / 点状词汇

- **1×1 round plate / stud / 圆点** — a data point, an item, a unit; count them for quantity — *degree, set membership.*
- **1×1 round printed tile / 印花圆片** — a coin, token, status dot, or stamp — *state, verdict.*
- **Cheese slope (1×1 wedge) / 楔形砖** — a small directional accent, a roof detail — *accent, finish.*

## The Cleverness Rule / 巧用原生件

- **Reach for the native element before a generic shape.** Need "stop"? Use the octagon sign or striped barrier, not a red cube. Need "flow"? Use an arrow road-plate, not a drawn arrow. Need "coupled"? Mesh two gears. Need "alarm"? A trans-red stud lights up.
- **Let the element carry the meaning so labels can stay sparse.** A traffic light already says block/hold/go; you don't also need three text tiles.
- **One or two native "hero" elements per build**, not a prop dump — the gear train OR the checkpoint, foregrounded; the rest is plain brick mass.
- **Vary which native elements you use across images** so builds don't all reduce to roads-and-buildings — a mechanism build (gears, levers) looks nothing like a signage build (signs, barriers, lights) even for related topics. This fights the "每张都差不多" feeling at the element level.
- **Match the element to the domain** (`domain-adaptation.md`): traffic signage for routing/process, gears/levers for mechanism/feedback, screens/panels for data/AI, flags/plinths for org/ownership, garden/home parts for life topics.

## Accept / Regenerate

Accept:

- Meanings are carried by **real native LEGO elements** (arrow road-plates, signs, barriers, gears, traffic lights, trans-studs) that a brick-holder reads instantly — not generic cubes or drawn arrows.
- The native element genuinely fits the relation it serves (gear=coupling, barrier=boundary, arrow=flow), per `connection-grammar.md`.
- One or two hero native elements are foregrounded; the rest is quiet brick mass.
- The element vocabulary varies across a user's images so builds don't all collapse into the same roads-and-buildings town.
- Everything stays original — generic part types only, no licensed sets, no LEGO logo.

Regenerate:

- A generic 3D shape or a drawn arrow stands in where a native element exists (a red cube for "stop" instead of a sign/barrier; a painted arrow instead of an arrow road-plate).
- Native elements are scattered as decoration without serving the relation.
- Every build reduces to the same roads-and-gray-buildings vocabulary regardless of topic.
- A native element contradicts its meaning (a green light over a blocked road).
- It reproduces a specific licensed set or the LEGO logo.

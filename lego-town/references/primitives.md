# Primitives / 零件原元素

The reusable atomic brick elements every LEGO Town scene is built from. Primitives are the **nouns** of the kit; the build archetype and minifig action are the **verbs**. Pick the elements first, then assemble them. **Reuse the same element for the same meaning** across every image in a series — that consistency is what makes a multi-image set feel like one town instead of ad-hoc blocks.

Read with `style-dna.md` (material, palette, labels) and `brick-library.md` (the verbs and roles).

Each item: concept it carries — element/build note — labels it commonly hosts.

## Structural Bricks / 结构砖

- **1×N / 2×N Brick / 基础砖** — one unit, idea, or module mass; the standard studded brick; the workhorse — hosts a printed-tile name on its face.
- **Plate / 薄板** — a thin layer or a sub-step; one-third-height brick; for layering and fine height — hosts a layer tile.
- **Tile / 平滑片** — a finished, closed surface, or a **label**; smooth, no studs on top = "done / sealed / printed" — hosts the printed label itself.
- **Slope / Wedge / 斜坡砖** — a roof, a ramp, a chute, a transition; angled brick — hosts a direction marker.
- **Baseplate / 底板** — the ground, the world, the context everything clutches to; large thin plate with studs — hosts road lines, district names, a town title.
- **Foundation Slab / 地基板** — the shared base others depend on; a thick large plate/raised platform — hosts a "底座 / 前提" tile.
- **Pillar / Column / 立柱** — a load path or a brace; stacked round/Technic bricks — hosts a load tile.
- **Wall / Fence / 墙·围栏** — a boundary or enclosure edge; a run of bricks or fence pieces — hosts a boundary name.
- **Brick-Built Letters / 拼字** — a title or key word built from bricks; studs-up letterforms — *is* the label.

## Connection & Motion / 连接与传动

- **Connector Plate / Coupling / 连接板** — where two modules join; a plate/clip bridging two builds — hosts an interface tile.
- **Road / Rail / Conveyor / 道路·轨道·传送带** — a route, sequence, or flow path on the baseplate; printed road plates or a belt of plates with cleats — hosts station numbers, direction signs.
- **Bridge / 桥** — a handoff across a gap; an arch or span — hosts an interface label.
- **Hose / Tube / 软管** — a flexible/loose connection or a feed; a bendy element — hosts a flow tag.
- **Technic Beam & Pin / 梁与销** — a rigid mechanical link or frame; beams pinned together — hosts a structure tag.
- **Gear / 齿轮** — coupling, transmission, feedback; meshed Technic gears — hosts a loop-type tag.
- **Axle / Lever / 轴·杠杆** — a trigger or control input; a Technic axle/lever — hosts an on/off tag.
- **Hinge / Turntable / 铰链·转盘** — a conditional, pivoting, or rotating link; a hinge brick — hosts a "可调 / if" tag.
- **Rubber Band / Chain / 皮筋·链条** — tension, pull, suspension; an elastic or chain element — hosts a force tag.

## Enclosures & Containers / 围合与容器

- **Walled Plot / 围合地块** — a bounded context/domain; fenced baseplate area — hosts a district name.
- **Building / 楼** — a module, service, or actor's home; a brick structure, optionally cutaway — hosts a building sign.
- **Gate / Barrier Arm / 闸门·道闸** — a filter, permission, or threshold; a Technic arm up/down — hosts a gate-state and rule tile.
- **Hopper / Funnel / 漏斗** — convergence/collection; a sloped container — hosts a "汇聚 / collect" tile.
- **Bin / Tray / 收集箱·托盘** — output, residue, or a sorted pile; a small open box — hosts a contents tile.
- **Box (Set Box) / 盒子** — the bundled whole (Box-Art mode); a product box — hosts the original product name.

## Optics, Light & State Parts / 光学与状态件

- **Transparent Brick / 透明砖** — active signal, energy, "live" or "highlighted"; clear / trans-color element — hosts nothing; the color is the meaning.
- **Light Brick / 灯砖** — a lit/triggered state; a brick that reads as glowing — hosts an "on" tag.
- **Window / 窗** — a view in or limited access; a window element — hosts a caption.
- **Flag / Banner / 旗·横幅** — a milestone, claim, or title; a flag on a pole — hosts a short milestone label.
- **Studs Exposed vs Tiled-Over / 露点·盖片** — *to-build* vs *done*: bare studs = unfinished/open slot; smooth tile cap = completed — see `state-coding.md`.

## Measures & Tools / 度量与工具

- **Brick Seesaw / Balance Beam / 跷跷板·天平梁** — tradeoff or weight of evidence; a beam on a fulcrum — hosts side-value tiles.
- **Slider on a Rail / 滑杆** — a degree or adjustable level; a marker on a Technic rail — hosts min/max ticks.
- **Gauge / Dial / 仪表** — an intensity/health reading; a printed round tile with a needle build — hosts a unit/needle label.
- **Brick Ruler / 砖尺** — a standard of comparison (count studs); a measured plate — hosts unit ticks.
- **Stamp Tile / 印章片** — approval/decision; a printed stamp tile a minifig places — hosts 通过/搁置/拒绝.
- **Counter / Counts Box / 计数盒** — a quantity; a row of 1×1s or a number tile — hosts the count.

## Label-Container Primitives / 标签容器原元素

Labels live on objects, never in empty space. Short readable labels (2–6 Chinese characters by default), attached to elements.

- **Printed Tile / 印字平滑片** — a smooth tile with a short printed name; the default label.
- **Signboard / 招牌** — a sign panel on two stud-posts; for module/district names.
- **Road Sign / 路牌** — a small directional sign on a route; for stage/direction/station.
- **Plinth Plaque / 底座铭牌** — a caption on a pedestal; for an honored/owned module.
- **Flag Label / 旗标** — a short word on a flag; for a milestone or claim.
- **Brick-Built Letters / 拼字** — a key word built from bricks; for a hero title.
- **Instruction Call-out / 说明书零件框** — a boxed part icon + count, e.g. `2×4 砖 ×3`; Instruction-Sheet mode only.
- **Step Number Badge / 步骤编号** — a number in a circle; Instruction-Sheet mode.
- **Sign Strip / 句条** — one short readable sentence on a long tile; only when it sharpens the takeaway.

## The Minifig Kit / 小人仔构造件

The minifig is assembled from standard minifig parts; the role accessory does the storytelling.

- **Head** — cylindrical, original simple expression (calm by default; state-coded when needed). No licensed/trademarked face print.
- **Torso (printed)** — an original printed front signalling the role (hi-vis vest, lab coat, sash) — not a brand/IP print.
- **Legs** — standard C-curve; posed only as the action needs (mid-step, crouched to build).
- **Hands (claw)** — hold exactly one role tool.
- **Headgear / Accessory** — the role marker: hard hat, goggles, mayor's chain, satchel, wrench, clipboard.
- **Scale** — smaller than the build; usually 8–18% of canvas height; secondary to the structure, essential to the action.

Reaffirm: **original** minifig only. No LEGO logo, no trademarked smiley, no licensed character (Star Wars/Marvel/etc.), no real-person likeness. Not a Minecraft blocky figure. Not a generic 3D mannequin.

## Baseplate / Camera / Composition Primitives

- **Focal module** — the one build the eye lands on; only one per image.
- **Quiet baseplate** — generous empty studded ground around the focal module; breathing room.
- **Depth layers** — foreground build + action, mid modules, back skyline of low bricks.
- **Camera** — a 3/4 hero angle for Finished Build & Box Art; a flatter, even, slightly-top vector view for Instruction Sheet; a straight-on or 3/4 with aligned floats for Exploded View.
- **Ground** — a seamless studio sweep (finished/box) or an off-white page (instruction/exploded).

## Carrier / Road Variants / 路径变体

The baseplate road/conveyor is the reader path. Its form implies the flow:

- **Straight / 直行** — a simple uninterrupted sequence.
- **Forking / 分叉** — a decision/switch point splitting into lanes.
- **Looping / 环回** — a feedback loop or repeat (often a closed conveyor / gear loop).
- **Broken / 断裂** — a failure or disconnect (a gap, a collapsed span).
- **Merging / 汇合** — separate lanes joining (into a hopper).
- **Climbing / 攀升** — a sloped ramp = rising effort or value over stages.

## Assembly Rule / 装配规则

- Choose the simplest sufficient set of elements; add more only when the system's precision needs it. Group into ≤7 modules.
- One element carries one meaning; don't overload a brick with two unrelated jobs.
- Assign each meaning to its element once, then reuse it across the series — the foundation of the 串联 layer in `series-and-chaining.md`.
- Keep semantic colors and label containers consistent with `state-coding.md` and `style-dna.md`.

## Accept / Regenerate

Accept: every object is a named primitive from this kit; the same meaning maps to the same element across the set; labels sit on label-container primitives; the minifig is built only from the Minifig Kit and is original; the element set is the simplest that carries the idea; bricks look real (studs, tubes, ABS sheen).

Regenerate: an off-kit ad-hoc/voxel/clip-art object appears; a stock 3D block stands in for a real brick; the minifig gains a licensed face or brand print; one element is forced to mean two things; the scene is a flat brick-textured chart with no depth or focal module.

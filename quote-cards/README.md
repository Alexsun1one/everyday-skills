# Quote Cards / 金句知识卡片

> 把一个想法变成「会被收藏、被转发」的文字卡片：金句卡、干货清单、读书笔记、数据卡、步骤卡、概念卡。

Quote Cards 面向所有想把一句话、一个观点、一条干货做成好看卡片的普通人——发朋友圈、做小红书、整理读书笔记、分享一个数据或概念的人。它不是一个模板包，而是一套卡片工作流：先想清楚「这张卡只讲哪一个想法、谁会存它、为什么」，再用排版把它做成层级清楚、留白舒服、值得截图保存的卡片。

卡片只有一个任务：让人看完想存下来、想转给朋友。它不是封面，不靠标题党骗点击；它的全部功力都在排版纪律上。

## 它解决什么问题

普通人做文字卡常掉进几个坑：信息过载（一张卡塞五个观点）、像 PPT（每行字一样大、平权项目符号、到处加标题栏）、像海报（大图把字压住）、排版没层级（眼睛不知道先看哪）、配色花（彩虹色 + 渐变光）。

Quote Cards 想要另一种状态：

- 一张卡只讲一个想法，一眼看到重点那一行
- 层级清楚：先看到什么、再看到什么、最后看到什么
- 留白是设计，不是浪费；卡片会呼吸
- 配色克制：纸 + 墨 + 最多一个强调色，最多两种字体
- 装饰安静：一条细线、一个大引号、一个小色块、一个数字——不要贴纸、不要发光
- 看起来像一张你愿意截图保存、转发给朋友的卡，而不是一页幻灯片或微商图

一句话判断：如果这张卡讲的东西跟直接复制一段文字没区别，排版就什么都没加上去，这张卡还没做完。

## 适合谁

适合：想做金句卡 / 语录卡 / 干货清单 / 读书笔记卡 / 数据卡 / 步骤卡 / 概念卡的内容作者、读书人、知识分享者、做笔记的人。

不适合：要「会被点开」的社交封面 / 首图（用封面类 skill）、信息密集的数据图表、被大图主导的海报、logo、表情包。

## 工作流

1. 读这句话 / 这条干货 / 这段读书笔记 / 这个数据 / 这个概念。
2. 找出这张卡只讲的那一个想法。一卡一想法。
3. 想清楚谁会存它、为什么。
4. 从 `references/card-archetypes.md` 选一个卡片类型（金句 / 干货清单 / 读书笔记 / 数据 / 步骤 / 概念）。
5. 跑「收藏测试」：有没有一个值得整张卡的想法？有人会存吗？
6. 定层级：眼睛先看到 1、再看到 2、最后看到 3。
7. 用 `references/typography-system.md` 锁排版——一个主元素、强烈的字号对比、统一对齐、充足留白。
8. 用 `references/style-dna.md` 定外观和配色。
9. 用 `references/prompt-template.md` 生成最终图像提示词。
10. 一次生成一张。
11. 用 `references/qa-checklist.md` 验收，不过就重做。

## 安装

### Codex

```bash
mkdir -p ~/.codex/skills
cp -R quote-cards ~/.codex/skills/quote-cards
```

重启后：

```text
用 $quote-cards 把这句话做成一张金句卡：「你以为的稳定，只是别人懒得换掉你。」先规划，先别生成。
```

### 其他 Agent（Claude Code / Cursor / Hermes / OpenClaw）

不需要 Codex Skill 格式，把 `SKILL.md` 和 `references/` 当作项目指令 / 规则 / workflow prompt 贴入即可。核心链路是：
`一个想法 -> 谁会存它 -> 收藏测试 -> 选类型 -> 定层级 -> 锁排版 -> 最终提示词 -> QA`。

注意：跨 Agent 复用的是规划和排版工作流；最终成图质量取决于图像模型，尤其是中文文字的渲染。文字渲染不干净时，按 `prompt-template.md` 的 text-fix 流程修，或先把英雄区留空、再在编辑器里把准确文字叠上去。

# Intent Reading / 读心

The fastest way this skill dies is sameness: the first image wows, but after repeated use everything "feels the same" because the skill drew the obvious town without reading what the user actually wants. Intent reading is the anti-template layer — fill the Intent Brief **before** the Collaboration Test, and let the intent pick the mode and tone.

A vague ask ("画个流程图", "做得好看点", "搭个图", "整一张") almost never means what it literally says. Translate "what they said" into "what they need."

## The Intent Brief

Fill this before anything else:

```text
intent brief:
- literal ask:
- real goal (impress / clarify / persuade / reassure / teach / document / sell / explore):
- audience (exec / new hire / customer / peer / public / child):
- desired feeling (wow / now-I-get-it / this-is-safe / this-matters / I-trust-this / warm / amused):
- author stance (advocating / warning / explaining / celebrating / mourning / neutral):
- the one sentence the user would stake everything on:
- content-specific particulars that MUST appear (not generic to the topic):
- mode implied by intent (not by topic):
- density (minimal / standard / rich):
- label language and length:
```

## Goal → Mode Map

The same system is a different image for different goals. Let goal pick the mode.

| Real goal | Best mode | Why |
| --- | --- | --- |
| impress / sell | **Panorama** hero shot, or **Two-Page Spread** | a wide dense beautiful town wows; a comparison sells the new way |
| clarify / teach | **Cutaway** or **Sequence street** | drilling inside is how you teach "what's really going on" |
| persuade | **Two-Page Spread** | old vs new, the reader sees the win themselves |
| reassure / this-is-safe | **Panorama** calm warm town, green flags | a quiet orderly town with everything healthy reads as "under control" |
| document | **Cutaway** or **Sequence street** with full labels | the reference look |
| explore | **Panorama** with one focal question mark | an open map inviting exploration |

## Audience → Density & Labels

- **Exec / customer**: minimal labels, one focal zone, big picture. Don't drown them in stations.
- **Peer / engineer**: standard density, full labels, allow technical signage.
- **New hire / learner**: rich cutaway, every floor labeled, a clear path.
- **Public / child**: warm simple town, few labels, big friendly animals, one clear handoff.

## Tone → Emotional Coding

Tone tunes the state coding and the palette.

- **Celebrating / launching**: green flags, smoke rising, eased satisfied expressions, a checkered flag on the output. Warm full palette.
- **Warning / at-risk**: one red pennant, a worried expression, a Firefighter approaching, darker smoke. Keep the rest calm so the alert pops.
- **Mourning / post-mortem**: a closed shop, an awning rolled up, a dozing animal, a gray sky. Desaturate slightly.
- **Neutral / explaining**: calm plain faces, neutral flags, balanced palette. Let the cooperation do the talking.
- **Playful / for-kids**: rounder animals, brighter accents, motion lines, a hot-air balloon.

## The One Sentence

Every brief has one sentence the user would stake everything on. Find it before drawing. Examples:

- "Our new process removes the bottleneck at QA." → the image must show the bottleneck being unblocked.
- "Data engineering is where the magic happens." → the image must make the data engineer's trade look skilled and central.
- "The old way was chaos; the new way is flow." → two-page spread, chaos vs flow.
- "This system has a hidden layer everyone forgets." → cutaway with the hidden floor (a Mole) highlighted in gold.

If you cannot find the one sentence, ask the user. Do not draw a generic town.

## Content-Specific Particulars

The **Swap Test** (see `variation-engine.md`) says: an image that could move to a different article on the same topic without anyone noticing has failed. The cure is to pull the **content-specific particulars** — the names, the numbers, the actual steps, the real example — into the image.

Bad (generic): "a software team collaborates" → draws a generic office-town.
Good (precise): "our 4-person platform team: Alex on infra, Sam on API, Jo on data, Max on call" → draws a cutaway with 4 floors, each floor's animal labeled with the real role and the real person's animal double.

Read the source for:
- the real role names, the real step names, the real tool names
- the actual number of stages
- the specific bottleneck, the specific risk, the specific tradeoff
- the real example the user keeps returning to

These belong in the image as labels, flag colors, and station counts. A precise image is locked to its document.

## Anti-Patterns

- "It's a process, so I'll draw a sequence street." — did you read the goal? A process for an exec might be a panorama, for a new hire a cutaway.
- "I'll just use the bakery street again." — did you diverge? See `creative-divergence.md`.
- "The user said flowchart, so I'll draw a flowchart with animals." — no. The user said flowchart but needs a town. Translate.
- "Same animals as last time." — vary the species to fit the domain.

## When to Ask

If after filling the brief you still cannot find the **one sentence** or the **content-specific particulars**, ask the user one short question. Do not draw a generic town — a generic town is worse than a delayed one.

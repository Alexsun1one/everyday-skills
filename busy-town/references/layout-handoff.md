# Layout Handoff / 版式交接

Use this reference when a Busy Town image will be placed inside another artifact: README, article, WeChat post, social card, slide, doc, dashboard, landing page, or knowledge base.

Busy Town creates the **cooperation image**. The outer layout may own the headline, body copy, call to action, platform ratio, and caption.

## Handoff Fields

Return these fields when planning a generated asset:

```text
final container:
image role:
recommended ratio:
safe margin:
headline inside image: yes/no
caption outside image:
crop guidance:
background requirement:
handoff owner:
```

## Text Ownership

### Image Owns
- shop / floor / vehicle labels
- short state flags
- exact data chips that belong to a status object
- comparison page banners
- story/process beat markers on signposts

### Outer Layout Owns
- title
- subtitle
- paragraph explanation
- citations
- long conclusions
- author note
- CTA
- platform-specific metadata

If a generated image already contains too much headline or paragraph text, regenerate with fewer labels instead of relying on layout cropping.

## Ratio Guidance

| Container | Ratio | Notes |
| --- | --- | --- |
| README / article figure | 16:9 horizontal | default |
| Social-card image well | wide crop, strong safe margins | avoid edge labels and corner flags |
| Slide center image | 16:9 or 4:3 | leave text-safe zones if the slide adds title/bullets |
| Comparison spread | 1:1 or 4:5, or a wide 16:9 with a clear gutter | keep both pages readable when cropped |
| Trade close-up card | 1:1 or 4:5 | kit labels need quiet space |
| Icon / sticker | usually not Busy Town | route to sticker skill |

## Crop & Margin Rules

- Keep the **focal cooperation zone** in the central 70% — never at the extreme edge.
- Hot-air balloons, roof flags, and page banners need **top safe margin** so social crops don't cut them.
- Two-page spreads need a clear **gutter** that survives a center crop or a fold.
- Dense panoramas: prefer regenerating a slightly simpler town over asking the layout to crop chaos.

## Handoff Notes

In final delivery, include:

- full image path
- compressed preview path if created
- recommended caption (outside the image)
- any text that should stay outside the image
- any crop warnings
- whether the image is safe for small display (phone / thumbnail)

## Anti-Patterns

- stuffing the README title into the town banner
- delivering a panorama with labels on all four edges (unsuitable for social crop)
- assuming the slide will "just put text on top" without leaving a quiet zone
- handing off a text-empty town and expecting the caption to carry the whole meaning

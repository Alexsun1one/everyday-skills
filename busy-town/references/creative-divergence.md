# Creative Divergence / 创意发散

For any non-trivial idea, do **not** commit to the first town concept that comes to mind. Sketch 2–4 genuinely different concepts first, then converge on the one that fits this content most precisely. **Precision beats novelty** — but precision often requires reaching past the obvious default.

The biggest failure mode of this skill is auto-defaulting to the **bakery street** (or the **server village**) for every request. Divergence is how you avoid that.

## The Divergence Step

After the Intent Brief and before the Collaboration Test, list 2–4 candidate town concepts. Each concept is a different **(metaphor world × mode × lead role POV)** combination. Then pick the freshest one that still passes the Collaboration Test.

Template:

```text
concept A (default): bakery street, sequence mode, Baker lead
concept B: harbor town, panorama mode, Harbor Master lead
concept C: hospital tower, cutaway mode, Owl Inspector lead
concept D: fire station, two-page spread, Two Firefighter leads

picked: C — because the source is about a system with hidden layers, and a cutaway tower makes the hidden floor (the Mole) the focal point. Bakery street wouldn't show the hidden layer.
```

Rules:
- Concepts must be **genuinely different**, not variations of the same idea (different camera angle is not a different concept).
- At least one concept must come from the **Town Metaphor Library** below (not the bakery default).
- Pick the concept that **fits this content most precisely**, not the one that looks coolest. If bakery street truly fits best, use it — but only after considering the alternatives.

## Town Metaphor Library

A library of fresh town-world metaphors. Reach for one when the default (bakery street / server village / office town) feels too obvious. Each maps a domain concept to a storybook town.

### For pipelines & flow
- **Bakery street / 面包街** — wheat → flour → dough → loaf. Default for transformations. Use when it fits; don't auto-default.
- **Orchard sorting line / 果园分拣线** — harvest → wash → sort → pack → ship. Best for **filtering** and **quality gates** (the sorter at the screen is the gate).
- **Harbor / 港口镇** — ships dock → cranes unload → customs stamps → warehouses store → carts dispatch. Best for **import/export, ingestion, boundary crossing**.
- **Rivermill town / 河磨小镇** — a river powers a chain of mills. Best for **a process powered by a shared resource**.

### For systems with hidden layers
- **Mine & surface town / 矿上山下镇** — a surface town with an underground mine below (cutaway shows both). Best for **hidden infrastructure / front-and-back systems / the layer everyone forgets** (the Mole).
- **Theater town / 戏台镇** — a stage (frontstage) and wings/backstage (backstage). Best for **what-users-see vs what-runs-it**.

### For response & incident
- **Fire station / 消防站** — bell rings → poles slide → trucks roll → hoses out → mopped up. Best for **incident response, alerts, on-call, recovery**.
- **Hospital tower / 医院塔** — intake → triage → treatment → recovery → discharge. Best for **care, recovery, healing, repair at scale**.

### For routing & branching
- **Railway junction / 铁路枢纽** — a switchyard where cars are routed to different tracks. Best for **routing, branching, dispatching**.
- **Post office / 邮政总局** — letters sorted into pigeonholes, then dispatched. Best for **message routing, fan-out, queues**.
- **Crossroads market / 岔口集市** — a square where multiple roads meet. Best for **convergence, exchange, many-to-many**.

### For tradeoffs & decisions
- **Market square with a scale / 司秤集市** — a town square centered on a big balance scale. Best for **tradeoffs, negotiations, weighing options**.
- **Town hall debate / 镇公所辩论** — a mayor on the balcony, two advocates below. Best for **tension, unresolved forces held in balance**.

### For storage & memory
- **Library tower / 图书馆塔** — a tall tower of card-catalog drawers and shelves. Best for **knowledge base, memory, indexing, retrieval**.
- **Archive cellar / 档案地窖** — a quiet cellar below a busy town. Best for **cold storage, audit trail, history**.

### For growth & ecosystems
- **Garden / farm town / 田园镇** — rows, seasons, a Farmer, growth over time. Best for **organic growth, ecosystems, compounding**.
- **Forest edge town / 林边镇** — a town at the edge of a wild forest. Best for **a managed system next to an unmanaged one (the wild)**.

### For oversight & governance
- **Civic town with a town hall / 民政镇** — a mayor on the balcony, a courthouse, a customs gate, a fire station. Best for **governance, public services, org charts**.
- **Lighthouse town / 灯塔镇** — a coastal town with a lighthouse watching over. Best for **monitoring, alerting, oversight, the watcher**.

## Choosing a Metaphor

Pick the metaphor whose **native cooperation** matches the source's relationship most precisely:

| Source relationship | Best metaphor |
| --- | --- |
| transformation chain | bakery street / orchard line / rivermill |
| filtering / quality gate | orchard sorting line / customs house |
| hidden layer | mine & surface / theater |
| incident / response | fire station / hospital tower |
| routing / branching | railway junction / post office / crossroads |
| tradeoff / weighing | market square with scale / town hall debate |
| storage / memory | library tower / archive cellar |
| growth / ecosystem | garden town / forest edge |
| oversight / governance | civic town / lighthouse town |
| import/export boundary | harbor town |
| simultaneity / everything-at-once | any, as a **panorama** |

## Anti-Patterns

- Auto-defaulting to bakery street for every transformation. Consider orchard line, rivermill, forge.
- Auto-defaulting to server village for every system. Consider mine & surface, theater, library tower.
- Picking a metaphor because it's novel, not because it fits. A cool-but-wrong metaphor is worse than the boring right one.
- Reusing the same metaphor across a series when the source's relationships differ. Match metaphor per image.

## Convergence

After listing 2–4 concepts, converge with a one-line justification:

> "Picked the **harbor town / panorama** because the source is about ingesting external data through a customs-like boundary, and a harbor's crane-and-customs-gate is the most precise physical analog. The bakery street was rejected because there's no transformation — only ingestion and gating."

Then proceed to the Collaboration Test with the picked concept. If the picked concept fails the test, go back and pick another — do not force it.

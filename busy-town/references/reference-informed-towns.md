# Reference-Informed Towns / 参考事实镇

Use this reference when the subject has real-world visual facts: a harbor, hospital, school, factory, fire station, post office, farm, brand operations floor, scientific apparatus as a workplace, historical workshop, or any industry that is visually easy to get wrong.

References are for **truth and recognition**, not for copying style — and never for copying Richard Scarry pages.

## When To Gather References

Gather references when:

- the user names a specific industry, place type, apparatus, brand ops, or historical workshop
- a wrong vehicle, uniform cue, or shop layout would mislead the reader
- the audience expects recognizability ("this should feel like a real harbor")
- the topic is niche or has changed recently

Skip reference gathering only when the subject is generic or explicitly symbolic ("a cozy town about morning routines").

## What To Extract

Record:

```text
what it is:
must-have roles:
must-have vehicles / tools:
stable layout cues:
process or mechanism:
common confusions:
source notes:
uncertainty:
```

Translate references into Busy Town cues:

- role set (who works there)
- vehicle / tool family
- shop / building types
- street or cutaway layout conventions
- era/context cue only when meaningful
- color convention only when meaningful (e.g. safety orange on a worksite)

Do not:

- paste logos or trademarks
- trace source photos or diagrams
- mimic another artist's layout
- reproduce any Scarry scene, character, or spread
- add unsupported "realistic" details that the source doesn't need

## Prompt Block

```text
Reference-informed cues: [subject] should include [must-have roles/vehicles/layout cues]. Translate these cues into the Busy Town world with hand-painted watercolor, original anthropomorphic animals, warm muted palette, and cooperation as the diagram. Do not copy source images, do not reproduce Scarry characters or scenes, and do not add unsupported details.
```

## Special Case: User Asks For A Scarry Character Or Scene

This is a reference request that must be **refused as copy** and **fulfilled as original equivalent**:

1. Identify the *job* the named character/scene was doing (inspector at a gate, bakery street sequence, fire response).
2. Recast with a different species + original outfit + original shop layout.
3. Say so in the output: "画了原创等价物，未复刻原作角色/场景。"

## QA

Accept if:

- the subject is recognizable to the intended audience
- key roles / vehicles / layout cues are present and labeled correctly
- uncertainty is not hidden as fact
- animals still perform cooperation rather than posing beside a reference model
- no Scarry likeness or trademark appears

Reject if:

- a mechanism or industry process is wrong
- a historical or cultural scene implies a false event
- a brand/model cue is confused with a different entity
- reference detail overwhelms the cooperation argument
- the image drifts into photo-real or into a copied storybook page

# CRM Demo v2 — 完整 10 步工作流走查(原文权威版)

> 这是 `demo-crm-v2.html` 的"判断链路文档"。**先有判断,再有页面**。
> 上次 demo 失败,因为跳过了 Stage 0 判断层 + 选错风格 DNA(Linear 给中文 CRM)。这次严格按 workflow/01 的 10 步走。

---

## Step 1:想法压成一句话

**原始想法**:"做一个 CRM 客户管理页"

**压成一句**:
> "为 10-200 人的销售团队,提供一个能快速看见'今天该跟谁联系、哪个客户有风险、哪个该升级'的客户列表 + 详情页,让销售每天少花时间在'找客户',多花时间在'联系客户'。"

---

## Step 2:用户任务清单

| 用户 | 真实任务 | 成功标准 | 先做? |
|---|---|---|---|
| 销售 | 看今天该联系谁 | 一眼看见"最近未联系天数"排前的客户 | **先做** |
| 销售 | 找出有风险的客户 | 一眼看见"流失风险/降级风险"标签 | **先做** |

| 销售主管 | 看团队客户总览 | 知道谁的客户多、谁有风险 | 第二阶段 |
| 销售主管 | 分配客户 | 把客户转给合适的销售 | 第二阶段 |

## Step 3:成功标准

销售来这一页的**主任务**:"找+判断+跟进"。具体:

1. **第一眼**(0-2 秒):看见"今天该跟谁联系"——按"最近未联系天数"倒序,顶部就是最该跟的
2. **第二眼**(2-5 秒):扫一眼哪些客户有风险标签(红色 = 高风险流失,黄色 = 阶段停滞过久)
3. **行动**(5-15 秒):点客户 → 详情抽屉 → 看最近 3 次互动 → 记新跟进 → 关闭回列表,**位置保留**

## Stage 0:6 张判断卡

### Card -1:原则自检

```
5 指标自评:
□ 目标清晰(销售 5 秒能说出"今天跟谁")— 5 分目标
□ 路径短(主路径:列表→点开→跟进→关闭,4 步)— 设计目标 4 步内
□ 反馈快(每次跟进提交有 loading + 成功 Toast + 失败保内容)— 必做
□ 错误少(跟进失败保留草稿,删除二次确认)— 必做
□ 情绪稳(空状态写"还没有客户,点击导入",离线提示本地草稿)— 必做

4 原则:
□ 层级:第一眼 = "未联系天数"数字最大最亮(权重 5)
□ 克制:列表只放 5 列(身份/阶段/最近联系/风险/负责人),不放电话/邮箱/公司名等
□ 一致:所有按钮 8px 圆角,所有卡片 12px,所有 badge 6px
□ 反馈:跟进提交→loading→Toast+撤销 5 秒

6 老规律:
□ 菲茨:主按钮"新建跟进"放右上角,够大
□ 希克:默认筛选只 3 项(我的/全部 + 阶段 + 风险),高级折叠
□ 米勒:列表行字段 5 个,不超过 7
□ 雅各布:列表左+详情抽屉右(销售用过的所有 CRM 都这样)
□ 多尔蒂:列表加载用骨架屏
□ 特斯勒:阶段默认值"线索",联系人默认"所有",不让销售每次选
```

### Card 0:任务场

```
主任务:找出今天该跟的客户 + 记录跟进
用户角色:销售,工位上用电脑,每天上午 9 点打开看一遍,急(主管盯 KPI)
5 动作里承担的:找 + 判断 + 处理
用户路径图:登录→列表(第一眼看见未联系天数)→点客户→抽屉看互动→写跟进→保存→Toast+撤销→关闭回列表(位置保留)→点下一个
用户带走:跟进记录存进系统
系统留下:客户.最近联系时间 更新,客户.下次提醒 计算
```

### Card 1:复杂度守恒

```
用户脑子里冒的疑问:
1. 今天该跟谁?(归销售:看未联系天数)
2. 这个客户现在什么阶段?(归系统:阶段 badge 自动显示)
3. 上次聊了什么?(归系统:自动记录互动)
4. 有没有风险?(归系统+团队:风险规则由运营配置,系统自动算)
5. 我能不能改这个客户?(归系统:权限规则)
6. 改完谁会知道?(归系统:通知规则)
7. 改错了能撤销吗?(归用户:5 秒撤销窗口)
8. 这个客户归我吗?(归系统:归属显示)

假简单风险:列表只显示客户名 → 销售要点开才知道该不该跟
假灵活风险:让销售选时间区/语言/币种 → 系统应基于上下文默认
默认值清单:阶段默认"全部",时间区默认"本地",币种默认"¥",归属默认"我的"
AI 介入点:暂不引入(AI 总结放第二阶段,避免无规则生成)
```

### Card 2:真简 vs 空简

```
主路径几步:4 步(列表→点开→写跟进→保存)
5 个异常:
  - 做错:写错跟进内容 → 编辑(在抽屉内)
  - 脏数据:客户名很长 → 截断 + tooltip 显示全名
  - 无权限:查看别人的客户 → 详情只读,加锁图标
  - 中断回来:写一半切走 → 草稿自动保存,回来恢复
  - 撤销:刚保存的跟进 → Toast 5 秒撤销
诚实答:这是真简(5 异常都备齐了)
```

### Card 3:视觉层级(★ demo 翻车主因,这次重点)

```
层级三问:
  - 第一眼必须看到:"最近未联系天数"(数字)+ 客户名 + 风险标签
  - 第二眼需要看到:阶段、负责人、最近联系日期
  - 可以先不看到:客户编号、创建时间、内部 ID

视觉权重 5-3-2:
  - 权重 5(最多 3 个):
    · "最近未联系天数"数字(24px, weight 600, 红色 if >7 天)
    · 客户名(16px, weight 600)
    · 风险标签 badge(高饱和色)
  - 权重 3:阶段 / 负责人 avatar / 最近联系日期(14px, weight 400, 深灰)
  - 权重 2:客户编号 / 创建时间(12px, weight 400, 中灰)

主色用在哪 3 类(不得超过):
  - 主按钮("新建跟进")— 飞书青 #1456F0
  - 风险标签(高=红,中=橙,低=不显示)
  - 阶段标签的不同色(线索=灰,商机=蓝,成交=绿)

主动调淡的元素:边框(用 #E8EAED 极淡),分隔线(虚化),低频操作(进更多菜单)

闭眼 1 秒测试:睁眼第一眼看到的应该是列表顶部那个最大的红色数字"15 天"(最久未联系的客户)
```

## Stage 0.5:选模式

**主任务 = "从一堆客户里找 + 处理" → 列表-详情模式**(patterns/01)

```
列表三眼分层:
  第一眼:客户名 + 最近未联系天数 + 风险标签
  第二眼:阶段 + 负责人 + 最近联系日期
  第三层(默认隐藏):客户编号、创建时间、内部 ID

详情五区:
  标题区:客户名 + 阶段 badge + 风险 badge
  主信息区:客户基本信息、最近 3 次互动摘要
  属性区(可编辑):负责人、阶段、下次提醒、备注
  关系区:关联商机、关联合同(本 demo 简化,只放联系人)
  历史区:跟进记录时间线

打开方式:右侧抽屉(快速查看 + 轻量编辑),保留列表上下文
  · 整页详情:用户点"打开完整页面"才进(本 demo 不做)
  · 左右分栏:本 demo 不做(等宽屏优化时第二阶段加)
```

## Step 5:组件状态矩阵

### 客户列表行

| 状态 | 视觉 | 行为 |
|---|---|---|
| 默认 | 白底 | - |
| hover | 浅灰底 #F7F8FA | 显示[更多]按钮 |
| 选中(checkbox) | 浅蓝底 #E8F0FF | 批量操作栏出现 |
| 已读 | 默认 | - |
| 加载中 | 骨架行(灰色块占位) | 保留筛选栏 |
| 空(初始) | 居中插画 + "还没有客户,点击导入" + [导入客户]按钮 | - |
| 空(筛选无结果) | 居中 + "没有匹配的客户" + [清空筛选] | - |
| 错误 | 顶部 Banner"加载失败,请重试" + [重试] | 保留已加载的行 |

### 详情抽屉

| 状态 | 视觉 | 行为 |
|---|---|---|
| 加载中 | 抽屉骨架屏(标题/字段/时间线占位) | 列表上下文保留 |
| 正常 | 五区填满 | - |
| 跟进提交中 | [保存]按钮 loading,输入框保留 | 防重复提交 |
| 跟进失败 | 输入框下红色 inline"网络异常,内容已保留,请重试" | 草稿不丢 |
| 权限不足 | 详情只读,右上角锁图标 + tooltip | 允许查看 |
| 离线 | 顶部黄 Banner"离线中,跟进将保存在本地,恢复后自动同步" | 不假装成功 |

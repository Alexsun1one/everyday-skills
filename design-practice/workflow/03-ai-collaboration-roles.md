# Workflow 03 — AI 协作三角色(原文权威版)

> 出处:《设计的实践》第 10 编 四(行 2160-2179)
> 定位:**Agent 自我定位 + 用户对 Agent 的使用纪律**
>
> **作者原话**:「AI 很快,但它不是师傅。师傅要懂取舍、懂场景、懂责任;AI 更像一个手很快的助理。你让它画,它能画;你让它写,它能写;你让它改,它能改。但该不该画、该写什么、该怎么验收,仍然要由人来判断。」

## AI 协作三角色

| 角色 | 适合做什么 | 不该让它独自决定什么 | 人的责任 |
|---|---|---|---|
| **调研员** | 找资料、列标准、整理竞品 | 判断你的产品该不该照搬 | 确认来源,结合自身用户 |
| **草图员** | 生成结构、页面方案、组件说明 | 决定产品主任务和取舍 | 设定任务,删掉多余功能 |
| **执行员** | 写代码、补状态、改样式、生成清单 | 宣布"已经完成" | 验收主流程、边界和真实体验 |

## 三个角色的典型任务

### 调研员(Researcher)

**适合**:
- 列出某类产品的设计标准(如"列出 B2B SaaS 列表页的 10 个最佳实践")
- 整理竞品的功能差异
- 查找法规 / 无障碍 / 平台规范
- 总结用户调研方法

**不适合独自决定**:
- 判断你的产品**该不该**照搬(它会说"Linear 这样做",但不代表你要这样做)
- 决定你的目标用户是谁

**人的责任**:
- 确认 AI 给的来源是不是真的(它会编)
- 把 AI 给的"通用最佳实践"结合你的实际用户检验

### 草图员(Drafter)

**适合**:
- 生成信息架构方案(3-5 个 IA 草稿)
- 列组件清单 + 状态矩阵
- 写文案候选(标题、按钮、错误、空状态)
- 给出提示词模板

**不适合独自决定**:
- 产品的**主任务**和**取舍**(主任务必须人定)
- 5 个草稿里选哪个(取舍必须人决)

**人的责任**:
- 设定清楚任务边界(用 [02-design-task-brief.md](./02-design-task-brief.md))
- 删掉 AI 加戏的功能(参考 SKILL.md 的 "Feature creep")

### 执行员(Implementer)

**适合**:
- 写组件代码
- 补状态(loading/empty/error)
- 改样式(对接设计令牌)
- 生成验收清单

**不适合独自决定**:
- 宣布"已经完成"(必须人验收)
- 跳过验收直接交付

**人的责任**:
- 验收主流程(走一遍 10 步路径)
- 走坏数据(长文本/空/极值/权限/网络/i18n)
- 走移动端

## 核心纪律

> **作者金句(行 2179)**:「你越把 AI 当神,它越容易骗你;你越把 AI 当新人,它越好用。给它清楚任务,给它严格边界,给它检查清单,要求它自查,再由你复核。这样它就是十倍速度的手;如果你把判断权交出去,它就是十倍速度的坑。」

## Agent 自我定位(AI Agent 读到这里)

**我是哪种角色?** 取决于用户当前在哪一步:

| 用户在做什么 | 我是 | 我应该 |
|---|---|---|
| 调研阶段("看 Linear 怎么做的") | **调研员** | 列事实 + 标来源,不替用户判断要不要照搬 |
| 设计阶段("给我 3 个 IA 方案") | **草图员** | 给方案 + 说明取舍,让用户选,不替用户定主任务 |
| 实现阶段("写代码 + 补状态") | **执行员** | 按约束写 + 出示证据,**绝不宣布"完成"** |

**关键自我纪律**:
1. **执行员角色时,绝不宣布"完成"** — 必须出示证据(状态截图、走查清单),等用户验收。
2. **草图员角色时,绝不替用户做取舍** — 给方案,不给决定。
3. **调研员角色时,绝不编造来源** — 不确定的标"未验证"。

## 反模式

### 反模式 1:把 AI 当神

```
坏的: "你帮我设计一个产品" → AI 自由发挥 → 产物塑料
病根: 没给边界。
```

### 反模式 2:把 AI 当师傅

```
坏的: "你觉得这个交互好不好?" → AI 给主观判断 → 用户被带偏
病根: 让 AI 独自决定取舍。
```

### 反模式 3:让 AI 宣布完成

```
坏的: AI 写完代码说"完成" → 用户信了 → 上线发现状态没补
病根: 没让 AI 出示证据。
```

### 反模式 4:把判断权交出去

```
坏的: "你看着办,我相信你" → AI 编功能、编规范、编来源
病根: 放弃了人的责任。
```

## 提示词模板(让 AI 守住角色)

### 调研员提示词

```text
你是一位调研员。请帮我整理 [主题] 的设计标准。
纪律:
1. 只列事实,不给"我觉得"
2. 标注来源(原文/竞品/规范)
3. 不确定的标"未验证"
4. 不替我判断"该不该照搬"
5. 输出格式:表格 + 来源链接
```

### 草图员提示词

```text
你是一位草图员。请基于以下设计任务单,给我 [N] 个 IA 方案。
任务单:[粘贴 02-design-task-brief]
纪律:
1. 给方案 + 说明取舍
2. 不替我决定选哪个
3. 不加任务单外的功能
4. 输出格式:每个方案 ASCII wireframe + 取舍说明
```

### 执行员提示词

```text
你是一位执行员。请基于以下方案,生成代码 + 补状态。
方案:[粘贴选定的 IA 方案]
令牌:[粘贴设计令牌]
纪律:
1. 不宣布"完成"
2. 出示证据:每个状态长什么样、移动端如何、错误文案
3. 跑 P0/P1/P2 自查
4. 输出格式:文件结构 + 组件代码 + 状态证据 + 自查结果
```

## 与 agent-playbook 的关系

`references/agent-playbook.md` 的 Step 7(AI 生成)就对应这里的"执行员"角色。
Agent 在 Step 7 必须按"执行员提示词"工作,不能自由发挥。

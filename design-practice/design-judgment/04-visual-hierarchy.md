# 判断卡 3 — 视觉层级(六杠杆 + 层级三问)

> 出处:《设计的实践》第 7 章(行 4924–5060,原文 22 次提及"视觉层级")
> 严重度:★★★ — **这是 AI 产物最常翻车的地方**。AI 默认把所有元素字重、字号、颜色调成差不多,产物立刻"塑料感"。
>
> **特别说明**:这条卡是 demo-crm.html 翻车的直接原因。当时我整页所有标题、数字、按钮、链接字重都是 500,字号都在 14–16px,所有 accent 都是 violet,导致"一屋子人同时喊话"——没有重点。

## 一句话

> **用户打开页面的第一秒,眼睛会自动寻找重点。如果所有东西都一样大、一样粗、一样亮,用户就要自己判断重点——这就是设计在偷懒。视觉层级的任务,就是替用户安排注意力。**

## 注意力分配图(必看)

```
用户注意力(很有限)
   ├── 第一眼 → 页面主题 + 当前状态(我是谁?现在怎么样?)
   ├── 第二眼 → 核心信息 + 主行动(我要看什么?我要做什么?)
   ├── 第三眼 → 辅助信息 + 次行动(还需要什么?)
   └── 需要时 → 低频信息 + 高级设置(什么时候用?)
```

**不是所有信息都要第一眼看到。** 第一眼只负责把用户带进任务,后面的信息按需要展开。AI 默认把所有信息"民主化"——这就是塑料感的源头。

## 视觉层级六杠杆

高手做层级,不靠花哨颜色,靠下面六个杠杆的组合:

| 杠杆 | 怎么影响注意力 | 使用建议 | AI 最常犯的错 |
|---|---|---|---|
| **大小** | 越大越先被看见 | 标题、关键数字、主信息用大字号 | 所有字号都 14–16px,平 |
| **字重** | 越粗越有重量 | 标题 600/700,正文 400,数字可 600 | 全页 500,没层级 |
| **颜色** | 高对比和主色更显眼 | 主行动、状态、链接用主色 | **满屏主色**(accent 滥用) |
| **位置** | 上方、左侧、中心更先被看见 | 主任务放主视觉路径上 | 主按钮藏右下角 |
| **留白** | 周围越空,越被强调 | 重要模块周围留呼吸 | 所有东西挤在一起 |
| **分组** | 相近元素被理解为一组 | 相关信息靠近,不相关拉开 | 字段和按钮乱混 |

> **原文章节 7.2 原话:高手做层级,往往不是靠花哨颜色,而是靠大小、字重、灰度、留白和对齐。很多高级界面看起来"淡",但你一眼知道重点在哪里,这就是功夫。**

## 层级三问(每页必填)

做任何页面,都问这三句话:

```
1. 用户第一眼必须看到什么?
2. 用户第二眼需要看到什么?
3. 哪些东西用户可以先不看?
```

### 示例:订单详情页

| 层级 | 内容 | 视觉处理 |
|---|---|---|
| 第一眼 | 订单号、状态、金额、客户、主操作 | 字号最大 / 状态色 / 主按钮放右上 |
| 第二眼 | 商品、配送、付款、备注 | 中等字号,分组,留白分隔 |
| 可以不看 | 系统日志、创建时间、同步 ID、历史版本 | 小字灰色 / 折叠 / 详情页深处 |

**不主动回答三问 → 页面把所有信息平均摊开 → 平均就是没层级 → 用户自己找重点 → 设计失败。**

## 好坏对照:同一个指标卡片

原文 7.4 案例,这是 AI 最常做错的:

### 差的指标卡片(AI 默认产物)

- 标题、数字、说明、趋势、按钮都差不多大
- 颜色很多(主色 + 危险色 + 趋势色 + 图标色)
- 图标很抢眼
- 主要数字反而不突出

### 好的指标卡片

- **数字最大**(比标题大 2–3 倍)
- 标题清楚但不抢(中等字重,中等灰)
- 趋势用小号文字 + 语义色(不抢主视觉)
- 图标只是辅助(小、淡)
- 操作只有必要时保留一个入口

| 元素 | 坏设计 | 好设计 |
|---|---|---|
| 指标数字 | 和标题差不多大 | **最大、最清楚** |
| 标题 | 又粗又亮 | 中等字重,说明指标含义 |
| 趋势 | 大红大绿抢注意力 | 小号文字 + 语义色 |
| 图标 | 大而艳 | 小而淡,只做识别 |
| 操作 | 多个按钮平铺 | 必要时只保留一个入口 |

## 视觉权重的"5–3–2 法则"(实操)

为页面分配视觉权重,大致遵循 5:3:2:

```
权重 5(第一眼)— 主标题 / 核心数字 / 主行动 / 关键状态
                 字号 24–32px,字重 600–700,主色或近黑
                 
权重 3(第二眼)— 次标题 / 常规数据 / 次要行动
                 字号 14–16px,字重 500,深灰
                 
权重 2(可以不看)— 辅助说明 / 时间戳 / 低频操作
                 字号 12–13px,字重 400,中灰
                 
权重 1(背景)— 装饰 / 容器 / 分隔
                 字号 11–12px,字重 400,浅灰或禁用色
```

**自检**:打开你做的页面,闭眼 1 秒,睁眼第一眼看到的东西,**是不是页面最重要的东西**?如果不是,层级失败。

## 视觉层级提示词(AI 自检用)

原文 7.6 提供的提示词模板,直接复用:

```
你是一名世界级 UI/UX 设计师。请评审下面页面的视觉层级。

页面说明:{粘贴页面描述、截图说明或代码}
用户主任务:{用户来到这一页最重要的任务}

请按以下问题分析:
1. 用户第一眼会看到什么?
2. 用户第一眼应该看到什么?
3. 哪些元素过度抢注意力?
4. 哪些重要元素不够突出?
5. 字号层级是否清楚?
6. 字重是否滥用?
7. 主色是否使用过多?
8. 留白和分组是否帮助理解?
9. 主行动是否清楚?
10. 低频信息是否太显眼?

请输出:
- 当前视觉层级问题
- 推荐的信息层级
- 推荐字号、字重、颜色、留白调整
- 修改后的页面结构
- 好坏对照说明

要求:
不要只说"更简洁"。
请明确指出哪些元素要变大、变小、变淡、移动、分组或隐藏。
```

## 层级清单(Stage 2 完成后必跑)

```
□ 用户第一眼看到的是不是最重要的东西?
□ 主标题、核心状态、主行动是否清楚?
□ 是否到处加粗?(应该只有标题 + 关键数字加粗)
□ 主色是否被滥用?(应该只在主按钮 + 状态 + 链接)
□ 低频信息是否太显眼?
□ 留白是否帮助分组?
□ 相关信息是否靠近?
□ 不相关信息是否拉开?
□ 危险信息是否只在需要时明确?
□ 页面是否能在 3 秒内看懂主次?
```

# 判断层 (Design Judgment Layer)

> 出处:《设计的实践》第 1–5、7、13 章
> 定位:Stage 0 / Stage 1 前置。在画任何 wireframe、选任何 style DNA 之前必须先过的判断关。
>
> **为什么单独抽出来**:之前 skill 重"视觉 + 组件 + 验收",轻"判断 + 决策"。产物 AI 味的根因之一就是跳过了判断层——AI 直接进 Stage 1 wireframe,把"好看"当成"好",把"列组件"当成"做设计"。这一层补的是**思想纪律**,不是规格。

## 判断层使用纪律(Agent 必守)

1. **顺序不可跳**:必须按 0→1→2→3→4 读。前一个判断决定后一个判断的输入。
2. **判断层先于 Stage 1**:Agent Playbook 第 2 步必须先填 5 张"判断卡",才能进 Stage 1 画 wireframe。
3. **判断卡 ≠ Intent Brief**:Intent Brief 描述"用户要什么";判断卡描述"我们决定怎么做、为什么这么决定"。两者都填。
4. **判断卡是产物的灵魂**:`examples/golden-task-manager.md` 里的 Intent Brief 必须配套 5 张判断卡。

## 判断卡通用模板(每个判断层文件末尾都有,复制即用)

```
【判断卡 N — <判断名>】
□ 用户主任务(一句话,动词开头):
□ 用户来这一页/这个 App 第一秒应该感知到什么:
□ 复杂度归谁(用户/系统/团队/AI):
□ 这是"真简"还是"空简":
□ 视觉层级三问:第一眼看什么 / 第二眼看什么 / 可以不看什么:
□ 这个判断会牺牲什么(tradeoff):
```

填不出来就别画 wireframe。填得模糊就回 Intent Brief 重新问。

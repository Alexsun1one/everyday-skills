# Notion 五层刀法完整拆解

> 出处:原文行 2444-2460。`armory/03-tokens-notion.md` 只拆了 ④System 层,本文件拆 ①Task ②Structure ③State ⑤Tradeoff 四层。

## ① Task 层 — Notion 把哪条主流程做顺了

**核心用户**:知识工作者（写会议纪要、做项目计划、整理知识库、搭任务表）。
**核心任务**:**用积木拼出自己的系统**——既给长期自由,又给新手扶梯。
**Notion 把"自由 + 上手"做顺的具体表现**:

| 观察 | 为什么这样设计 |
|---|---|
| 块系统（每个段落/标题/列表/数据库都是独立块,可拖动、可转换、可嵌套） | 长期自由:用户能拼出任何结构,不被固定模板锁死 |
| 数据库（table/board/calendar/gallery/list 多视图） | 同一份数据,不同视角——任务用 board,日程用 calendar,清单用 list |
| 模板库（开会纪要、项目计划、OKR、wiki 等开箱即用） | 新手扶梯:不用从空页开始,直接套模板改 |
| 空状态引导（空白页给"试试 / heading、/ todo、/ database"） | 新手扶梯:命令菜单是上手第一步,空状态教 |
| 示例内容（新建 workspace 有 demo page） | 新手扶梯:不是空地,是有"第一块砖"的工地 |

**反塑料锚点**:原文行 2460:**"自由不是把用户扔进空地,而是给他积木、图纸和第一块砖。"**

## ② Structure 层 — Notion 的信息为什么这样安排

| 观察 | 为什么这样安排 |
|---|---|
| 左 sidebar（workspace 树形导航 + 收藏 + 设置） | 知识库结构层级深,树形导航是必须 |
| 主区:页面内容（块流式） | 块是基本单位,主区是块的画布 |
| 右侧抽屉:打开子页面/属性/反向链接 | 不切换上下文,在原地看详情 |
| 命令菜单（/ 触发块类型/操作） | 新手扶梯:不用找按钮在哪,/ 出菜单 |
| 数据库视图切换（top-right tabs:Table / Board / Calendar...） | 同数据多视角,视角切换不丢数据 |
| 页面内:面包屑弱（顶部小字）,标题大 | 知识库结构深,但视觉主角是当前页内容 |

**反塑料锚点**:Notion 的结构是**底层自由 + 表面引导**——块/数据库/页面/关系/模板给底层能力,模板/空状态/命令菜单/示例内容给上手扶梯。

## ③ State 层 — Notion 出事时怎么稳住用户

| 状态 | Notion 怎么做 |
|---|---|
| loading | 块骨架（匹配块形状,不是 spinner） |
| empty（initial,新页面） | 不显示"暂无内容",而是引导"/ heading 试试看"——空状态就是教学机会 |
| empty（filter,数据库无匹配） | "当前视图没有匹配项" + 清除筛选 |
| empty（permission,无权访问） | "你没有访问这个页面的权限。申请权限。" + 申请按钮 |
| error（保存失败） | inline 提示 + 自动重试,**块内容不丢** |
| error（同步冲突） | "这个块被别人改了,你的版本/他的版本,选一个"——不静默覆盖 |
| 离线 | 顶部 banner "离线编辑中,联网后同步"——可继续编辑,不怕 |
| 协作（多人同页） | cursor 显示其他人头像 + 选区高亮 + 头像列表 |

**反塑料锚点**:Notion 的"自由越大,引导越要清楚"——空状态不是"暂无数据",而是"试试这个命令"。这是新手扶梯的核心。

## ④ System 层 — 见 armory/03-tokens-notion.md

## ⑤ Tradeoff 层 — Notion 敢砍什么

| Notion 砍了什么 | 为什么敢砍 |
|---|---|
| 砍"开箱即用"的固定模板（默认是空 workspace,不是 SaaS 后台） | 自由是核心价值,固定模板会变成"另一个 SaaS" |
| 砍复杂权限模型（基础是 editor/full/viewer,不像 SaaS 那样多角色矩阵） | 知识库权限相对简单,复杂权限增加上手成本 |
| 砍重型模态（创建用 inline / 命令菜单） | 自由产品不能被模态打断流 |
| 砍装饰色（cream 底 + 黑 CTA,几乎无彩色） | 自由产品视觉要中性,彩色会"说话"抢走用户内容 |
| 砍营销化动效（动效极简,只在块拖动、菜单出现时） | 知识工作要专注,动效是干扰 |

**反塑料锚点**:学 Notion 最容易学歪的就是"加 cream 底 + serif 标题"——以为这就够了。原文行 2456:**"任何自由度高的产品,都要学这个平衡。**" 自由 = 块系统,扶梯 = 模板/空状态/命令菜单,**两者都要**。

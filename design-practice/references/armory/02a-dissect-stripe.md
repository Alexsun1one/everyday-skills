# Stripe 五层刀法完整拆解

> 出处:原文行 2385-2411。`armory/02-tokens-stripe.md` 只拆了 ④System 层,本文件拆 ①Task ②Structure ③State ⑤Tradeoff 四层。

## ① Task 层 — Stripe 把哪条主流程做顺了

**核心用户**:开发者（集成支付）+ 财务人员（管账）+ 终端用户（付款）。
**核心任务**:开发者要"边看文档边集成";财务要"看清楚钱去哪了";终端用户要"放心付款"。
**Stripe 把"可信"做顺的具体表现**:

| 观察 | 为什么这样设计 |
|---|---|
| 文档页:标题先讲结论（"这一节解决 X 问题"） | 开发者不是来读小说的,是要解决问题的,标题告诉他们这一节值不值得读 |
| 文档 + 代码并列（文字解释、代码示例、参数说明、错误提示互相支撑） | 开发者要边看边做,代码贴近说明位置,不用滚动找 |
| Dashboard 操作区:金额、状态、时间分级清楚 | 财务要快速识别"哪笔交易失败/哪笔退款",视觉层级帮他们扫读 |
| 支付页:品牌色（紫）小面积,只用在 CTA 和链接 | 支付页要让用户"放心",大面积紫色反而显轻浮 |

**反塑料锚点**:Stripe 的"高级"不是炫技,是**建立在秩序和信任上**。原文行 2387:"如果界面看起来像活动页,用户反而不放心。"

## ② Structure 层 — Stripe 的信息为什么这样安排

| 观察 | 为什么这样安排 |
|---|---|
| 文档:三栏（左 TOC + 中正文 + 右 on-this-page） | 开发者要随时知道自己在哪、能跳哪、本节有什么 |
| Dashboard:左侧 sidebar（业务导航）+ 主区（数据表格 + 图表） | 财务扫读优先,主区给数据,sidebar 给导航 |
| 营销页:hero 单 CTA + 渐变 mesh 背景 | 营销页要"转化",所以单 CTA + 视觉焦点 |
| 文档正文:标题 / 段落 / 代码块 / 提示框各有"声音" | 视觉层级稳定,大标题/说明/代码/提示/链接不抢话 |
| 错误说明在代码块旁边,不是页面顶部 toast | 开发者要就地看到错误 + 解释 + 修正方向 |

**反塑料锚点**:原文行 2403:"**复杂产品也可以清楚。清楚不是少,而是把复杂分层。**" 开发者不怕复杂,怕复杂没结构;财务不怕数字,怕数字没解释;用户不怕错误,怕错误不知道怎么修。

## ③ State 层 — Stripe 出事时怎么稳住用户

| 状态 | Stripe 怎么做 |
|---|---|
| loading | 骨架（交易列表行骨架）;图表用骨架占位 |
| empty（initial） | "还没有交易记录。当你开始接收付款,这里会显示。" + 引导链接（"如何集成"） |
| empty（filter） | "当前筛选下没有交易。" + 筛选 chip + 清除 |
| error（支付失败） | **错误码 + 人话解释 + 修正方向**（不是"Error 402",而是"卡被拒。原因: insufficient_funds。建议:用户换卡或联系银行"） |
| error（API 调用） | 请求 ID + 错误类型 + 文档链接 + 重试按钮 |
| error（网络） | 重试 + **请求体保留**（开发者不用重写一遍参数） |
| 权限 | viewer 看不到 API keys 字段,字段位置显示"You need admin role to view" |
| 重复提交 | 提交按钮 loading + disable,idempotency key 防重复 |

**反塑料锚点**:Stripe 的错误文案是**给开发者可行动的信息**——不是"出错了",而是"出错了,因为 X,你可以 Y"。这是开发者的核心需求。

## ⑤ Tradeoff 层 — Stripe 敢砍什么

| Stripe 砍了什么 | 为什么敢砍 |
|---|---|
| Dashboard 默认不堆所有图表（只显示关键 4-6 个） | 财务扫读优先,堆 20 个图表反而看不清 |
| 营销页不堆功能列表（hero 1 个 CTA,功能介绍在下方分段） | 转化优先,堆功能分散注意力 |
| 文档不堆所有 API（按场景组织,不按字母） | 开发者按场景查,不按字母查 |
| 品牌色不铺满（紫只在 CTA + 链接 + 重点） | 大面积紫色反而显轻浮,信任感来自秩序不来自颜色 |
| 不用模态弹错误（错误就地,在代码块旁边） | 开发者要就地看错误,模态打断流程 |

**反塑料锚点**:学 Stripe 最容易学歪的就是"加渐变 + 加紫色"——以为渐变多就是 Stripe 风。原文行 2401:"**渐变是气质,不是到处乱撒。**"

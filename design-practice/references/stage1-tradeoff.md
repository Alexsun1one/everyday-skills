# Stage 1 — Tradeoff Note (mandatory on every draft)

> No draft ships without a tradeoff note. The tradeoff note is layer ⑤ of the Five-Layer Blade — the judgment itself. Skip it and you've produced skin without skeleton.

## Why

Article line 3506: **"学世界级产品,不要学皮肤,要学判断."** The judgment lives in the tradeoffs, not the pixels. A draft with no tradeoff note is a draft with no judgment — it could have been generated by stamping a template.

Article line 2099: **"AI 很爱加戏,它觉得多就是好."** The tradeoff note is the discipline that stops AI from adding features. It forces the draft to declare what it doesn't do and why.

## Template (attach to every draft)

```text
TRADEOFF NOTE — [draft name]
================================

layer dug:
  [which of ① Task / ② Structure / ③ State / ④ System this draft digs]

good:
  [what this choice makes possible — be specific to the task]

cost:
  [what this choice sacrifices — every real choice has a cost; "none" means it isn't a tradeoff]

fit for:
  [which scene / user / task this layout serves best]

unfit for:
  [which scene / user / task this layout serves poorly]

how it 拼 into the product:
  [which other drafts this combines with, and what role it plays in the mosaic]

what it does NOT do (non-goals enforced):
  [the features AI would have added but this draft refuses]
```

## Examples

### Tradeoff note — B1 sidebar+list+drawer (task manager)

```text
layer dug: ② Structure

good:
  list stays visible while editing in the drawer — user doesn't lose place during batch reassignment

cost:
  drawer is ~400px, can't show wide tables in detail — financial data with many columns would feel cramped

fit for:
  task management where the user frequently jumps between items and needs context preserved

unfit for:
  complex records with many fields (invoices, reports) — those need full-page detail

how it 拼:
  pairs with A1 task-flow (the "edit" step happens in this drawer) and A3 object-state-permission (the drawer's edit button enabled-state comes from the matrix)

what it does NOT do:
  no Gantt chart, no calendar view, no time-tracking — those are this round's non-goals
```

### Tradeoff note — A3 object-state-permission (task manager)

```text
layer dug: ③ State (deep)

good:
  makes the data lifecycle and role boundaries explicit — every button's enabled-state and every list's filter has a source of truth

cost:
  adds upfront design work before any pixel is drawn — feels slow but prevents P0 bugs

fit for:
  any product with CRUD on a persistent object (which is most products)

unfit for:
  single-screen tools with no persistence (a calculator, a converter) — skip this draft there

how it 拼:
  this is the SKELETON — every B structure draft's button states, every A2 state-matrix draft's permission-empty wording, and the Stage-2 restore all source from this matrix

what it does NOT do:
  no role creation UI this round (roles are fixed: viewer / editor / admin / author); no custom workflows
```

## The cost test

Article line 3506 implies: **a tradeoff with no cost is not a tradeoff — it's a wish.** If the `cost` field reads "none" or "nothing", the draft hasn't really committed to anything. Push harder:

- "good: cleaner" / "cost: none" → **fail**. What did you give up to get cleaner? Density? Information? Feature count? Name it.
- "good: fits mobile" / "cost: less density on desktop" → **pass**. Real cost, named.

## The 拼-in test

Every draft must answer how it combines with the others into a product. A draft that doesn't combine is a solo shot — and solo shots are what AI generators produce. This skill assembles mosaics, not galleries.

- Bad: "this is a nice kanban view." — doesn't say what it pairs with
- Good: "this kanban (B2) pairs with A3 (object-state-permission) to drive the card enabled-states, and with A2 (state-matrix) to handle the empty/error per column."

## Failure modes

| Failure | Symptom | Fix |
| --- | --- | --- |
| No tradeoff note | draft ships without one | mandatory — no note, no ship |
| Cost = "none" | wish, not tradeoff | push: name what was sacrificed |
| No 拼-in | draft stands alone | name at least 2 other drafts it combines with |
| No non-goals | draft does everything | enforce 3 non-goals from the Task Card |
| Layer not named | "this is a layout draft" | name the specific layer (①-⑤) it digs |
